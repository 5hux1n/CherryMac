# 宝可梦键盘 USB 硬件验证

设备：CHERRY MX 3.0S Pokémon Wireless，USB VID `046A`、PID `01CE`。以下结论来自实际键盘测试，不能泛化为所有 CHERRY 键盘。

## 已验证的报告与命令

Report ID 4，64 字节。头部：报告 ID、两字节小端校验、命令、长度、两字节小端偏移、状态/标志，随后最多 56 字节数据。校验为请求命令及其后字节之和。

| 命令 | 用途 | 实测 |
| --- | --- | --- |
| 03 | 设备信息 | 读取 34 字节 |
| 05 | 灯效参数 | 从偏移 0 读取 56 字节；偏移 56 的请求被拒绝 |
| 06 | 写灯效参数 | 标志 55；12 个官方可见模式、亮度、速度、方向与单色／彩虹参数写入、完整读回和恢复通过；外观待确认 |
| 07 | 出厂键位表 | 126 个三字节记录；不随自定义映射改变 |
| 08 | 当前自定义键位表 | 读取 378 字节；后续键位写后校验应使用此命令 |
| 09 | 写键位表 | 实体计算器键输出了 ⌃⌥⌘C；测试后恢复原来的 Consumer 0192 |
| 0A | 自定义颜色 | 读取 126 个 RGB 三字节记录 |
| 0B | 写颜色 | 计算器键与 W 键 RGB 改动、自定义模式 8、完整读回和原配置恢复通过 |
| 14 | 读取宏区 | 每块最多 54 字节，偏移 0…3070 共 3071 字节读取成功；偏移 3071 被拒绝 |
| 15 | 写宏区 | 未绑定实体键的 30 字节短宏写入、完整读回及原区恢复成功 |
| 1B | LED/矩阵索引 | 前 126 字节主要是 00…7D，隐藏位置为 FF；不是自定义键位表 |
| 01、02 | 其他型号的事务命令 | 此固件返回 FF；不可忽略拒绝并当成成功 |

初期用 07 校验 09 会错误地判断写入无效。09 回复回显完整写入包，但只凭回显不能证明实际生效；本次进一步用实体键报告确认了组合键输出。08 是按相邻读写命令结构推断后进行实际只读查询得到的接口，不来自官方已公布文档。

## 修饰键残留与恢复

实体测试检测到按下后立即恢复键位表，恢复早于实体键松开，可能让固件按新映射处理释放，遗漏旧映射的修饰键释放。这次出现鼠标操作异常；测试退出后系统仍显示 Option 按下。发送软件释放事件无法清除硬件状态。按下并松开 Ctrl、Alt、Win 后用户确认已恢复正常，系统修饰键状态为 0，08 读取的键位表与原始表一致。

后续每个写入和恢复分块都检查实体输入状态与系统修饰键，使用单调时钟等待所有键连续 200 毫秒松开。配置基线已变化时拒绝覆盖；备份失败则不发送写入。HID Usage 0 是数组空值哨兵，不能当作仍按住的键。未能确认松开则中止写入。写前备份必须使用 08 的当前配置，不能使用 07 出厂表覆盖已有自定义映射。
