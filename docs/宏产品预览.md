# 宏怎么用

当前公开版本为 [Mac 0.51.0](https://github.com/5hux1n/CherryMac/releases/tag/v0.51.0) 和 [PHP 0.50.0](https://github.com/5hux1n/CherryMac/releases/tag/web-v0.50.0)。[在线工具](https://cherrymac.goforit.si/app/) 使用相同网页版本。它们仍是预览版，新版宏存储范围的实体输出与断电保留尚待统一验收。[当前功能状态](当前功能与验收状态.md)

## 编辑与绑定

进入“宏”页面，新建宏，添加或录制按键步骤。支持键盘按键、修饰键和五个鼠标按钮；每个按下都须有对应松开。可调整顺序、等待时间，复制或删除宏。

步骤编辑另提供“复制步骤”和“清空本宏步骤”：复制把包含等待值的副本插入原步骤前；清空只改当前步骤草稿，已保存的宏和绑定保留。Mac 在“编辑步骤”窗口操作，取消可保留原步骤。清空后可添加或录制新步骤再保存；空步骤不能保存为可执行宏。删除宏或清空宏库则解除相关绑定，与步骤清空不同。

选择“指定执行次数”“按住持续”或“再次按键停止”，再点击“分配到所选键”。保存宏本身不会改变已有绑定的执行方式。解除绑定会把该键设置为禁用；这些操作先修改编辑区，需要另行写入。

单宏最多 762 个事件，总可访问宏区为 3071 字节。容量按实际绑定计算：同一宏绑定多个键会重复占用，未绑定宏只保存本地。旧配置可先点击“启用扩展宏编辑”转换草稿，再核对写入。界面里的等待总量是设置值，不代表实际固件执行时间。

## 录制

选择已保存或导入的宏时，录制界面会恢复它的固定间隔选项及毫秒值。Mac 可在录制窗口点击“采用录制设置”，网页可直接调整选项；然后点击“保存宏”保留设置，不需要重新录制。设置只影响之后的录制，已有步骤的等待时间须在步骤编辑器调整。官方格式没有单独保存“忽略间隔”选项，下次打开恢复为非固定的实际间隔；已录制的零等待步骤仍保留。

开始录制前选择替换、追加或插入位置，以及是否记录鼠标。Mac 另提供其他应用录制，需要对应系统权限；网页只记录当前页面收到的事件。

当前支持五个鼠标按钮。启用鼠标录制时遇到滚轮会取消本次录制并保留原步骤，避免生成尚未确认的事件编码。

## 写入与恢复

通过 USB 数据线连接键盘并切换有线模式，读取当前配置后核对宏变更。宏写入仅处理宏区及相关绑定键，灯效和普通键位草稿分别处理。

操作前保存备份和恢复记录，写入后读回核对。若键盘正在执行连续宏，请先按界面提示停止。点击“停止发送”只停止后续配置写包，不能代替停止正在执行的宏。

断开、取消或写入失败后，在“配置与备份”使用“恢复最近宏写入前配置”。恢复记录包含写前宏名称资料；旧记录或名称资料缺失时仍支持原始硬件数据恢复。不要把导入记录中的读回当作当前键盘状态。

## 保存文件

使用“导出当前配置”保留宏库、绑定和草稿。已导入本型号 Windows 官方模板时，可使用“导出 Windows 配置草稿”；它合并当前键位、宏、文本与灯效草稿，设备设置沿用模板。导入与导出不会自动写入键盘。

网页版数据保存在当前浏览器与网站本地，建议另行导出保存；清理网站数据会删除本地资料。PHP 包无需 Node 或构建，已有 PHP 时解压并运行 start.command。具体启动及包校验见[公开预览版发布](公开预览版发布.md)。

追加或插入录制时，窗口会显示扣除原步骤后的可录制事件数；空间不足时先删除步骤或改为替换全部。旧共享宏格式最多 256 个事件，启用扩展宏编辑后最多 762 个事件。手动添加、步骤编辑和录制采用同一限制，完整宏库仍受 3071 字节的总容量限制。
