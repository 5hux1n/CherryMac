## 写入与恢复

宏页写入只更新宏库和宏绑定键。普通按键及灯效草稿保留，可以另行处理。写入前核对改动并自动保存完整备份和恢复记录，写后完整读回。

当前源码的宏恢复也保留未写入的普通键与灯效草稿；恢复宏库及其绑定时丢弃未写入的宏绑定修改，避免旧库关联到新索引。本版已包含这项修正。

持续执行的宏需按提示先停止。操作时的“停止发送”只阻止后续配置写包，不能停止键盘内正在执行的宏。失败或取消后保留恢复资料；重新连接后，可在“配置与备份”使用最近宏写入前配置恢复入口。

宏名称、默认方式和官方配置来源资料存于本机。重新读取时，仅沿用与实际宏库和绑定匹配的本地资料。建议导出 JSON 保存；网页更换浏览器、网址或清理网站数据后，本地资料可能不可用。

## 导入、导出 Windows 配置

在“配置与备份”导入本型号官方 JSON。键位和宏进入编辑区，文本定义进入文本页；文本键保留当前功能，需要在文本页另行安装。导入不会自动写入键盘。

使用“导出 Windows 配置草稿”保存合并后的编辑结果。它会保留文本内容、共享引用和官方附加字段；同一键若同时有键位修改和文本绑定，会提示先解除冲突。已安装文本键若缺少对应定义，也会要求先核对。

灯效草稿也会合并：支持当前模式、亮度、速度、方向、多色、全局 RGB 和逐键配色，自定义配色需先导入包含完整颜色表的本型号官方模板；内置模式允许没有逐键颜色表的模板。隐藏颜色及未核对字段保留原值，设备设置仍沿用模板。导出不会写入键盘，灯效硬件写入仍未开放。点击读取时会重复核对默认键位表和 LED 索引；成功取得的映射随普通配置及读取备份保存，用于键盘图、取色和配色。映射读取失败时会显示原因并保留按键、宏读取结果；旧配置没有映射时继续使用原固定槽位草稿转换，尚未证明实体灯珠对应正确。文本页的单独导出保存该页模板；保存其他页面改动时请用配置页的合并导出。“导出当前配置”已附带文本页选中的草稿，两端可以离线导入；导入不会安装文本或开启输入服务。文本安装版本和恢复记录仍在文本页单独导出。导入没有文本的旧配置时会清空当前选中的文本草稿，已保存安装记录保留。

## 文本与网页联动

在“文本”页选择本型号官方 JSON，连接并读取键盘后编辑所选键的名称和多行文字。采用只生成草稿；安装前核对键位清单，再确认写入。解除绑定也需确认安装才会恢复官方默认按键功能。文本内容存于主机，键盘保存触发键；跨应用输入需要 Mac App 持续运行及辅助功能权限。

文本定义和完整恢复记录均可导出。恢复记录支持这两个版本之间互相导入，只在没有文本记录的新环境中载入；相同档案可重复导入，已有不同记录不覆盖。导入不会改键盘或自动启用文本输入，恢复时仍须读取并核对。

网页不用手动把 JSON 搬到客户端：先在客户端文本页点击“网页联动”，开启并复制本次联动码，再在网页粘贴并连接。安装并保存相同定义后，点击“启用 Mac 文本服务”，网页先释放 USB，再提交定义。保持客户端配置窗口开启；网页配置操作和宏录制前会等待服务停止、释放 USB，联系失败时停止操作。刷新后先核对旧联动状态，不自动开启新服务；关闭网页请求解除，失联超过两分钟会停止该网页启动的文本服务。客户端关闭联动或关闭配置窗口也会停止服务。
