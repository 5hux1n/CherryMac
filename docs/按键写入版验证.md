# Mac 0.9.0 / Web 0.3.0 按键写入版验证

2026-10-03。两端接入独立键位写入、备份恢复和自动日志，发布为测试版。完整 Windows 功能复刻尚未完成，宏和灯效实物写入仍按用户要求暂缓。此次构建及自动测试不访问、修改实体键盘。

## 实现与审查

- 写入权限固定于完整基线及目标键位表，只允许命令 09 的七个标准 54 字节分块，包括范围内恢复使用的原表。无授权的写入、灯效、宏和未知命令仍被底层拒绝。
- 普通键、修饰键组合、媒体键与禁用可编辑。Fn／CHERRY 内部键、隐藏位置、宏绑定新增或改动、保留错误码和修饰键误用为主键被拒绝。
- 发送前重新核对完整配置，写入前保存并验证备份；原生和网页均核对设备信息、键位、参数、颜色及宏区。按键写入不携带灯效或宏草稿，两端保留未发送的编辑。
- 每包写入前检查按键释放；包间至少约 1.5 秒，仅为当前保守策略，不声明固件最小处理时间。网页要求用户用鼠标确认并保持前台，浏览器不能证明整个系统所有按键都已释放。
- 读回不一致时，先重新读取并核对每块是否仍为本次原表／目标表，以及非键位数据是否未变，再尝试恢复。未知变化、释放检查或日志保存失败时停止后续写入。网页断线、超时或坏回复使会话失效，不盲目重试。
- 写入阶段、实际请求／回复、耗时、错误和备份位置自动记录，持久化失败阻止后续写包。客户端近期备份恢复也先读取、展示改动再确认；网页导入备份进入按键页。
- 客户端提供标准应用、服务与编辑菜单，并改为正常 Dock 应用；防止配置操作期间正常关闭窗口或退出。计算器由系统服务启动，不由键位写入流程监听触发。

## 有效检查

| 检查 | 结果与范围 |
| --- | --- |
| `bash Source/build.sh` | 原生离线自测通过，包括范围授权、完整备份、部分写入恢复、范围外变化中止、设备信息变更零写包和日志持久化失败；生成并校验签名与 plist |
| `node --test Web/tests/core.test.mjs` | 24 项通过；验证实际传输类的七包写入、授权撤销、过期基线、备份／释放／日志失败零写包、超时停止、活跃连接读回失败恢复 |
| `node Web/tests/browser-keymap.mjs` | 本机 Chrome 模拟 WebHID 完整操作通过；109 键、正常单键正方形、窄屏不溢出、深色、菜单与宏编辑、七包键位写入、灯效草稿保留、备份和诊断下载 |
| 诊断离线回放 | 模拟完整操作共 234 条记录，其中 5 条阶段记录、229 条有效请求／回复，无缺失回复及校验问题 |
| 旧版离线复现 | 固定历史代码与内存设备可重现通信中断后的部分配置；当前非键位写入入口零设备操作。不能证明真实灯效故障根因 |

所有新测试使用合成配置，不在公共仓库收录用户日志或配置。PHP 运行不需要 Node 或 Playwright；浏览器测试仅为开发工具。

## 证据与下一项

已有[计算器实体测试](计算器键实机验证.md)证明该位置在本次固件和 USB 环境下的映射、平衡输出、系统计算器启动、恢复以及用户确认断电后的保留。电源关闭依据用户对话确认，自动记录的是 USB 断开约 34 秒。

本版新界面、一般键位和网页传输尚需实际验收。模拟器不实现键盘固件、真实 USB 容错、灯光外观或系统识别行为。正常客户端新增 Services 菜单仍需核对实际前台服务触发；不宣称系统计算器快捷操作适用于所有应用。未知实际通信失败中的自动恢复也不保证成功。

下一项持续推进新版两端的按键实机流程，以及官方宏、灯效与设备设置的功能对照和离线实现。受暂停限制的实体灯效／宏测试单独等待，不终止完整成品目标。
