## 报告分派与宏边界（静态工具 v2）

定位到链接地址 `2F094` 的报告分派入口：从输入 byte3 取命令、byte4 取长度、byte5 取 16 位偏移，数据从 byte8 起；其具名路径检查 report ID 为 4。`2F0F0` 使用 Thumb 半字跳转表，表起点 `2F0F4`，174 项覆盖命令 03…B0。工具直接从真实表计算目的地址，并核对完整表摘要；不将表或字面量池反汇编出来的伪指令当作代码。

| 命令 | 固件分支地址 | 与现有实现的对应项 |
| --- | --- | --- |
| 03 | 2F3A2 | 设备资料读取 |
| 05 / 06 | 2F3BA / 2F250 | 参数读取／更新 |
| 07 / 08 / 09 | 2F3D6 / 2F3F4 / 2F412 | 默认键位／当前键位读取、键位更新 |
| 0A / 0B | 2F43E / 2F45C | 配色读取／更新 |
| 14 / 15 | 2F496 / 2F4B4 | 宏区读取／更新 |

宏读、写两个分支均要求 offset < C00 且 offset+length < C00，等于边界也拒绝。因此，从偏移 0 连续覆盖的最大字节数是 3071，与当前产品范围吻合；不是将容量扩展为 3072。更新分支从 payload 复制到目标 RAM 并设置状态字节；复制助手 `3A084…3A0EC` 的完整代码已核对为带对齐处理的字节／字复制。状态字节的后续保存与完成语义仍需继续追踪。

另逐一核对 64 组存储名称与相邻 RAM 指针：八个灯效项从 `20000D18` 起、八个键位项从 `20000A98` 起、48 个宏数据项从 `200054EC` 起，同组相邻地址均相差 64。结合已阅读的名称比较／长度检查片段，这是以块定位配置 RAM 的线索；48 个名字不表示允许 48 个宏，也不直接证明 flash 保存完成或主机可访问配置组数量。

工具 v2 固定核对八处入口／边界指令、五段代码摘要、整张跳转表、12 个具名命令目的地址及上述指针对。私有结果 `work/pokemon-firmware-dispatch-audit-20261006.json`，真实固定文件解析和 Python 语法检查通过。USB 上游调用链、校验和检查、所有命令副作用、保存完成和当前实机固件身份尚未证明；不开放额外写入、不执行升级、不把此静态证据当作真机验收。下一步沿保存标志与配置字段消费者核对持久化、完整默认和设备设置。

## 保存后端与返回值（静态工具 v3）

已定位配置比较／保存助手及其后端分派方法 33924。分派方法从 `20007384` 取后端对象，以后端函数表 +8 调用具名数据保存；没有后端时返回 -2，否则保留后端返回值。具体后端实例、物理 flash 写入和完成时机仍未闭合，不能将“进入保存助手”记作持久化成功。

| 数据 | 具名助手 | 标志字节 |
| --- | --- | --- |
| 参数 func_ram | 2E9D0 | 20009B28 |
| 配色 | 2EA48 | 20009B25 |
| 键位 | 2EC50 | 20009B27 |
| 宏区比较门槛 | 2EE24 → 2DEE8 | 20009B26 |
| device_version | 2EE64 | 20009B24 |

这些助手在共享状态字节 `20009B2B` 为 4 时跳过保存；该状态的含义和状态迁移尚未分类。键位和配色按 64 字节块比较数据，各有八个具名后端调用点。逐一核对这 16 个调用后紧接无条件分支，没有检查返回寄存器 r0。宏比较助手比较 3072 字节 RAM 与副本，一致时清除标志，不一致时进入另一保存方法；尚未穷尽其 48 个块的完整失败处理。

参数助手采用另一处理：来源 `20000CD8`、比较副本 `20006F2C`，长度 64，保存名称 `flash/func_ram`。后端返回非零时跳过副本更新和标志清除；零返回后才复制副本、清标志，数据未变化时直接清标志。保存变化参数之前，byte16 若为 4 则改为 2；字段含义、上游选择与本机固件是否一致仍待查，当前产品不增加归一化规则。

2EE64 保存的是 `flash/device_version`，来源 `20000C98`，与参数助手不是同一操作。它先清除自己的标志，后调用后端，没有检查返回值。不能因两个助手都保存 64 字节就把版本记录误认成参数暂存区。

工具 v3 增加六段完整代码摘要、保存指针常量、16 个具名调用的 Thumb BL 目的地址与后继分支、版本／参数保存调用和参数返回检查核对。固定文件只读解析、Python 语法与差异检查通过，私有结果 `work/pokemon-firmware-save-path-audit-20261006.json`。没有执行固件、更新、模拟行为或访问键盘。USB 回复与 RAM 读回尚不能证明保存后端成功，仍保留最终统一断电验证；不根据这些片段自动重试、不解释为旧黑屏根因、不扩大发送授权。下一步追踪保存调用的调度、具体后端及参数 byte16／设备设置消费者。
