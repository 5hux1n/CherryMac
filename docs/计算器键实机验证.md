## 程序约束与代码审查

`CalculatorKeyTestAuthorization` 只接受完整已验证型号基线，且原计算器位置必须为 `30 92 01`。它仅允许校验完全匹配的原键位表或仅修改计算器键的目标表；拒绝其他键位、灯效、宏、未知命令、偏移、长度、尾部数据或校验变化。

实际写入权限只编译进带 `CHERRY_CALCULATOR_TEST` 的研究构建。默认构建没有授权入口，USB 查询白名单继续阻止所有修改。离线自测覆盖原表／目标表允许、同分块其他键改动拒绝、非标准短块拒绝、灯效与宏拒绝、校验损坏拒绝，以及默认发布模式继续只读。

测试控制器复用生产写入、基线检查、备份和释放检查；写入和恢复各自创建、使用并关闭一个 USB 会话，避免跨线程复用持有运行循环的会话。完成、取消及 180 秒等待超时后请求恢复；无法确认按键释放、配置出现范围之外变化或无法读回时保留窗口及备份，不覆盖未知状态。受控测试仍有 USB 断线或程序被强制终止后无法自动恢复的限制。

系统快捷操作安装前备份原工作流与服务偏好，不清理其他服务。它由 macOS 执行；测试控制器的输入回调仅记录 4 个预期 HID 信号与状态。

## 开发者运行

需要 Xcode 命令行工具与已经核对的本型号 CherryMac 完整配置。首先编译并运行离线自测；自测不访问硬件或安装服务。

```sh
xcrun swiftc -D CHERRY_CALCULATOR_TEST Source/*.swift \
  -o /tmp/CherryMac-CalculatorTest \
  -framework Cocoa -framework IOKit -framework ApplicationServices
/tmp/CherryMac-CalculatorTest --self-test
```

实际测试会安装计算器系统快捷操作、临时改写计算器键并请求恢复。运行前关闭其他配置程序的设备会话，保持键盘 USB 有线连接。不要重复旧网页灯效操作。

```sh
/tmp/CherryMac-CalculatorTest --calculator-key-test \
  --baseline /absolute/path/to/verified-profile.json
```

按窗口提示操作。日志、原配置、临时目标及恢复读回默认保存在 `~/Library/Application Support/CherryMac/HardwareTests/`。也可显式提供 `--test-dir`。原始用户配置与日志不上传、不收进仓库。

## 断电保留测试

增加 `--power-cycle` 可进入独立的断电保留流程。此模式仍仅允许原表和只修改计算器键的目标表，普通发布版没有这个写入入口。

```sh
/tmp/CherryMac-CalculatorTest --calculator-key-test --power-cycle \
  --baseline /absolute/path/to/verified-profile.json
```

1. 程序先备份、写入并读回核对，关闭写入会话后提示断开。
2. 拔 USB 并关闭键盘电源。USB 消失后才允许勾选“已关闭键盘电源”。内置电池继续供电时，只拔 USB 不算断电；无法关闭电源时不必勾选，仅记录 USB 重连结果。
3. 从勾选确认起至少等 15 秒，再开电、接 USB 并切换有线模式。
4. 程序检测新的 USB 设备实例，使用新会话先只读配置，保存 `after-reconnect.json`。这一阶段不授权任何写入，不会为了测试而先重写目标表。
5. 若目标仍在，提示按一次计算器键核对实体输出，随后恢复原表；若已经回到原表，记录未保留并确认恢复，不重新写入目标；若出现范围之外变化，停止自动覆盖。

日志分别记录 USB 重连保留和用户确认断电后保留。USB 接口无法测量内置电池电源，电源关闭事实依据用户确认；设备移除、新实例及确认后等待时间由程序记录。若无法观察断开、缺少确认或等待不足，不宣称断电保留通过。断开期间取消或关闭窗口会等待原键盘重连后再恢复。

离线自测已覆盖保留／恢复原表／异常配置三类判定，以及未断开、原 USB 实例、只拔 USB、事后确认和不足 15 秒等不能作为断电证据的情况。断电实物结果需以具体会话日志为准。
