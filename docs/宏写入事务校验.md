# 宏写入与恢复范围

本页记录源码中的离线实现，不表示宏已开放写入或通过真机验收。当前顺序是完成宏模块，随后进行真机写入、执行和断电测试，通过后再推进灯效。

## 本次补齐

客户端与网页版增加同样的宏事务计划。计划复制并保存读取时的完整配置、目标宏区与键位，以及临时禁用宏触发键的状态；不依赖后续修改的编辑草稿。

- 只接受当前已识别固件的完整配置，设备信息、参数与颜色保持原值。
- 只允许宏绑定变化及移除宏后的普通／媒体键恢复；不能夹带其他普通键修改，不能修改内部或隐藏位置。
- 宏事件仍须按下／松开配对、索引有效且满足容量限制。
- 每个写包必须完整匹配本次原值、目标值或临时禁用键位。宏区只允许发送实际变化的 54 字节分块，末块最多 47 字节，恢复也遵守相同范围。
- 恢复前重新读取完整配置。键位逐块必须属于本次允许状态；宏区的每一块，包括本次未修改的块，必须属于原值或目标值。出现其他数据或灯效／设备变化就停止自动覆盖并保留备份。

客户端已有模拟宏写入器使用此校验，维持事件区先写、偏移 0 的头部最后写、暂时禁用触发键、等待有限宏结束、完整读回及范围内恢复。网页版目前增加的是纯计划，尚未接入宏写入传输权限。两端正常产品入口仍阻止宏与灯效写入。

## 验证范围

原生自测覆盖原值／目标／临时禁用包、部分宏块写入、不同字段的范围外变化、篡改包、未改变宏块、隐藏绑定、夹带普通键、原媒体绑定恢复及宏触发键迁移。模拟固件额外覆盖“写入已执行但回复丢失，同时参数发生额外变化”：停止恢复，不继续发包覆盖该变化。

网页核心测试覆盖相同的计划范围、输入与返回值的独立复制、部分写入、非法绑定和恢复原媒体键。测试不打开实际 USB，不计入真机验收。

## 宏模块仍待完成

当前写入计划暂只接受单次执行宏。次数、按住持续和再次按键停止已支持导入与编辑，但写入过程所需的停止／中止与恢复语义尚未完成。官方滚轮、文本动作及本型号可用性仍需核对；网页宏传输授权、逐包等待、可靠日志与恢复还需接入。完成这些代码和审查后，才启动用户已授权的真机宏测试和断电保留测试，日志自动保存。
