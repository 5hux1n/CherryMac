# 灯效独立验收版怎么用

Mac App 独立验收版 0.1.4 和 PHP 网页独立验收版 0.1.7 已打包，用于接下来统一核对灯效写入、重连读回及恢复。它们尚未通过真机验收，普通预览版仍保留原来的写入范围。按此前安排暂不开始测试，准备好统一验收时再使用。

## 打开哪个版本

Mac 包名为 `CherryMac-LightingAcceptance-0.1.4.zip`，内含 `CherryMacLightingAcceptance.app`。适用于 Apple Silicon、macOS 13 及更新版本，采用临时签名，尚未 Apple 公证。它使用独立名称和标识，不替换原来的宏与文本预览 App。

网页包名为 `CherryMac-Web-LightingAcceptance-0.1.7.zip`。电脑已有 PHP 时，解压后双击 `start.command`，用 Chrome 或 Edge 打开 http://localhost:8771/lighting-test.php 。无需 Node、安装依赖或构建；启动脚本不会打开浏览器。页面的完整配置编辑入口是 http://localhost:8771/ 。这次使用不同端口，本地备份不会自动沿用原来 8770 页面的浏览器数据。

退出其他 CherryMac、键盘配置软件和 Mac 文本服务，避免同时使用 USB。打开验收窗口或载入文件不会自动写入，只有明确选择、读取并确认操作后才发送。

## 准备一次灯效改动

在主配置页读取键盘，导入本型号 Windows 官方 JSON，编辑灯效并保存到编辑区。自定义配色需要官方原始 RGB 颜色表和读取到的 LED 映射；内置模式允许没有逐键颜色表。

Mac 在灯效页点击“独立灯效验收”，自动载入编辑区计划。网页点击“使用编辑区计划开始独立验收”，在新标签页载入计划；原页面先停止文本联动并关闭 USB，保留编辑区。浏览器需允许新页面。无需先导出、再导入计划；仍可沿用“核对并导出计划”的文件流程。

点击读取或选择 USB 键盘。页面会核对计划和完整配置；文件不符合目标、固件或发送范围时会拒绝。

## 写入、断电读回与恢复

1. 松开全部按键，确认写入。程序先保存完整备份和恢复记录，再逐包发送；失败中止，不自动重试。保持验收窗口或页面前台，完成前不要使用键盘。“停止后续发送”不能撤回已经发送的报告。
2. 写入与读回一致后，观察实际灯光是否符合设置。随后拔掉 USB、关闭键盘电源，点击关电确认。
3. 至少等待 15 秒，再开电、接 USB 并切换有线模式。重新读取，然后点击核对断电重连读回。过早重连不能作为本轮断电证据。软件记录 USB 拔插和你的关电确认，无法证明电池确实断电；灯光外观仍需要实际观察。
4. 点击恢复原始数据，核对键盘功能和灯光是否恢复。恢复前会重新读取并检查范围，原始 RGB 不再次缩放；发现不能识别的变化会停止。

遇到超时或断开时，保存资料，重新连接后载入独立恢复记录再核对。恢复过程中断也能保留原计划。没有最终读回的旧记录不会被当成“配置未变”，必须用当前设备读回重新检查。

## 日志怎么保存

Mac 点击“打开本轮资料”，里面包含完整备份、读取快照、操作日志、USB 拔插与关电记录，以及独立恢复记录。操作日志会注明开始、完成／取消／失败、错误和实际 USB 标识，并给出对应恢复记录的文件名；尚未发出首包的准备失败也有记录。关闭验收窗口后，主配置页需要重新读取键盘。

网页分别点击“下载本轮资料”和“下载独立恢复记录”。本轮资料中的 operations 记录操作种类、开始／结束、状态和错误，包括首包前失败。操作记录保存失败时不会开始配置操作，下载现有资料仍可用。备份与操作记录还会自动保存在当前浏览器、当前网址的本地数据库；清理网站数据前请下载。日志保存失败时仍可下载现有资料，文件会标注日志缺失。所有文件保存到本机，不自动上传。

两端独立恢复记录可以互相载入；导入只核对文件，不自动连接、写入或恢复键盘。

```sh

```

普通宏与文本预览打包命令不加此参数，继续排除独立灯效发送界面。源码中的网页研究入口默认关闭，只有设置 `CHERRY_LIGHTING_TEST=1` 才能进入。


0.1.1 增加读回设备与重连记录的核对：网页按本轮 HID 对象标识，客户端按实际读取接口的 registry ID 检查。读回过程中会话改变会拒绝；同型号其他设备的事件不能直接作为所选设备的读回证据。计时保留首次重连时刻，过早接回不能被后续事件覆盖；重新拔出需要重新确认关电。这些标识仍不能证明重连前后是同一实体键盘或电池实际断电。0.1.0 旧包保留，统一验收使用修正版。


0.1.2 简化编辑区到验收窗口的交接。计划仍重新校验，网页计划只可取用一次，十分钟后失效；载入日志保存成功后才启用操作。主配置页的研究按钮默认隐藏，只有独立研究包启用。两端均需要重新读取并明确确认后才写入，本版未进行真机测试。
