# CherryMac 使用说明

适用于 Mac 0.8.0 和 Web 0.2.0 界面预览版。当前只能读取、编辑与保存配置，全部 USB 写入停用。旧版写入说明不适用于本版。

## 先预览，或读取键盘

打开客户端或网页后，无需连接键盘即可预览编辑。正常单键为正方形，计算器与三个媒体按钮在右上角。

要读取当前配置，请用 USB 数据线连接并切换到有线模式。客户端点击“读取键盘”；网页使用 Chrome 或 Edge，点击“连接 USB 键盘”，在设备选择弹窗中选择 CHERRY。只有充电功能的线不能读取。

读取后会自动保存备份。如果读取或备份失败，页面会提示。读取不发送配置写命令。

## 按键功能

点选按键，再选择预设或自定义组合键，保存到编辑区。框选截图为 ⇧⌘4，刷新为 ⌘R。Fn 和 CHERRY 内部键保留内部功能。

计算器媒体键通常不会直接启动 macOS 计算器。客户端可以安装计算器快捷操作，再设置为 ⌃⌥⌘C；实体完整流程仍待验证。网页不能安装系统服务。

## 灯效

“内置灯效”设置模式、亮度、速度、方向和颜色，保存到编辑区。不同模式可能忽略部分选项。

“逐键配色”先选按键或区域，再选颜色与配色方式，点击“应用到所选键”。⌘ 点击可多选；也可选择 WASD、主键区、方向键、数字区或全部。选择“熄灭所选键”只改变这些位置的预览颜色。

网页版的 RGB 与强度位于“精细颜色”展开项。客户端可直接输入 RGB 或 HEX。内置模式的单色设置与逐键颜色选择独立。

逐键配色为静态，不支持每键独立动画。工程图展示编辑颜色，不模拟实体动画。

## 宏

添加按下、松开和延迟，每个按下必须有对应松开。保存宏，再分配到所选按键。当前仅支持执行一次的键盘宏，鼠标宏、循环与切换执行暂未支持。

客户端步骤文本示例：`A 按下 0`、`A 松开 50`，每步一行，数字为延迟毫秒。网页使用步骤列表编辑。

## 配置与备份

此页不展示键盘图。支持导入 CherryMac JSON，以及本型号的 Windows 官方配置；Windows 导入前先读取键盘。遇到不支持的绑定会拒绝整个导入，保留原编辑配置。

导出保存当前编辑区；撤销恢复读取时的配置，未连接时恢复演示配置。导入、导出与撤销都不会修改实体键盘。

客户端点击“打开自动备份”进入备份目录。网页点击“查看本地备份”，可下载旧备份或导入编辑区；导入不能恢复硬件。保留原浏览器与网址，避免清理网站数据。

## 设备与诊断

网页可导出排查资料，包含已有备份、当前编辑区和新版查询日志。文件仅下载到本地，不自动上传，可能包含宏内容；请自行选择是否分享。

客户端此页提供 Mac 端适配设置入口。适配默认暂停，启用 F5 等软件映射需要应用持续运行及系统授权。

Win 锁、6 键／全键模式、回报率等官方设置还在核对协议。灯效异常根因、宏实体执行、断电保留尚未确认，当前版本不提供硬件写入或自动恢复。
