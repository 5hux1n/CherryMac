# CherryMac 0.5 · 使用说明

当前软件支持 USB 配置编辑和读写，并保留可选 Mac 按键适配。宏存储的读写与恢复已完成短宏实测；宏实体执行和断电保存仍待验证。

## USB 配置

1. 连接 USB 数据线，键盘切换到有线模式。仅充电线不能传输配置。
2. 打开 CherryMac，在系统设置 → 隐私与安全性 → 输入监控中为 CherryMac 开启权限。退出并重新打开应用。
3. 点击“读取键盘”。成功后自动保存一份包含键位、灯效、逐键颜色和原始宏区的备份。
4. 点选键盘上的按键，在“键位”页选择功能，再点击“加入待写入配置”。图上的标记代表待写入改动。
5. 松开所有按键，点击“写入键位”；完成前不要使用键盘。程序逐块检查松键状态并校验当前自定义表。

在“灯效”页点选单键，输入 R、G、B（0–255）或六位 HEX 色号，或使用颜色面板。颜色强度调整 RGB 的明暗，设为 0 为黑色；“熄灭所选键”也可关闭选中键灯光。点击“应用配色到所选键”，最后点击“写入灯效”。

按住 ⌘ 点击或勾选“多选”可以逐个选键。也可选择全部按键、主键区、功能键区、数字区、方向键或 WASD，点击“选择”。横向／纵向渐变使用当前颜色和渐变终点色，并按照所选按键在图上的位置分配颜色。静态彩虹、皮卡丘与喷火龙是配色预设；点击应用后可以继续单独修改任意键。应用逐键配色会自动选择自定义模式，未选中的键和隐藏固件位置保持原颜色。

内置模式包括波纹、光谱、呼吸、霓虹、曲线、折返、放射、扩散、单点亮、常亮、闪电和自定义逐键颜色。调整模式、亮度、速度、方向及单色／彩虹选项后点击“加入灯效配置”，再写入。使用“将颜色用于内置灯效”可设置统一的单色；不适用的选项可能被某些模式忽略。

逐键配色是静态颜色，不能为每个键独立设置动画与速度。键盘图预览配色，实体键盘执行内置动画。12 个模式的 USB 参数与逐键颜色均已通过写入和完整读回测试；动画外观与断电后的保留情况仍待确认。更多验证依据见[灯效功能与验证](灯效功能与验证.md)。

键位和灯效分开写入，各自保留另一类待写入改动。键盘的 Fn 和 CHERRY 内部功能键暂时保留原功能。其他键位的固件支持程度仍需要进一步验证。

## 计算器键

“安装计算器快捷操作”会创建一个 macOS 服务，用 ⌃⌥⌘C 启动系统计算器。在“键位”页将实体计算器键设为“打开系统计算器”，加入配置后才能手动写入。

此方案由键盘发出组合键、macOS 执行服务，不依赖 CherryMac 按键监听。已分别确认硬件能发出组合键、系统服务菜单接受此快捷键；实体键完成启动的整体流程仍待复测。当前键盘保留原计算器映射。

## 宏与配置文件

在“宏”页选择按键、填写间隔毫秒，点击“添加按键”，会加入一对按下和松开步骤。也可直接编辑，例如：

```text
A 按下 0
A 松开 50
```

宏必须释放所有按键；不完整步骤不会覆盖已保存的宏。支持选择和删除已保存的宏。修饰键用“左 Control”“左 Command”等名称，每个按下都须配有松开步骤。

保存宏后，点选键盘按键，选择已保存的宏，点击“分配到选中的键”。最后松开所有按键，点击“写入宏与键位”；整个过程不要使用键盘。宏和绑定必须联合写入，键位单独写入不能引用尚未存储的宏。可存储未绑定的宏，后续再分配。

硬件宏目前为实验性功能，仅支持键盘按键和执行一次。鼠标、重复或切换执行模式暂不支持，遇到未知原宏数据会保留原始备份并拒绝覆盖。删除宏会把编辑区内关联按键设为禁用；仍须写入才能改变实体键。重新读取会使用“硬件宏 1”等名称，因为硬件数据不保存宏名称。

实物已完成未绑定短宏的写入、完整读回与恢复，尚未验证实体键触发；请勿把存储校验通过当成执行或断电保存的证明。

“配置文件”页可导入 CherryMac JSON 或本型号 Windows 官方 JSON，导出为 CherryMac JSON。“导入”只载入编辑区，“撤销待写入改动”返回最近读取的配置。Windows 导入前需先读取当前 USB 键盘。

自动备份目录为本机 `~/Library/Application Support/CherryMac/HardwareBackups`，可点击“打开自动备份”。写入前使用当前自定义表备份，避免把已有配置误当成出厂设置覆盖。

写入失败时，程序在确认全部按键已松开后尝试恢复。如果恢复也失败，界面会显示备份路径，此时重新读取实际配置。出现修饰键残留时，按下并松开 Ctrl、Alt、Win；仍异常时重新插拔键盘 USB。

## 可选 Mac 端适配

应用启动时默认暂停 Mac 端适配。菜单栏 → “Mac 端适配设置”保留 F5 在浏览器中执行 ⌘R、框选截图、计算器启动和自定义快捷键等功能；需要输入监控与辅助功能权限，并主动启用。

这种适配需要 CherryMac 运行，设置保存在 Mac 上。浏览器限定、学习按键、冲突检查、导入导出与普通键来源匹配仍保留。它与 USB 配置界面的配置文件不同。

匹配蓝牙设备 `0687:00E9` 与 USB `046A:01CE`。USB 配置不能通过蓝牙或接收器执行；无线写入能力仍未证明。应用关闭时，硬件已写入映射仍由键盘输出，但断电或切换连接后的保留情况尚未验证。

## 验证状态

逻辑测试覆盖键盘布局、来源匹配、暂停、快捷键、配置文件、宏平衡、编码、名称关联与编辑器暂存。模拟固件测试覆盖写前完整备份、过期配置拒绝、每个分块的松键检查、宏绑定解除、等待原宏结束、头部最后写、回复丢失、读回不一致和恢复失败。

实物测试及其限制见 [USB 硬件验证](USB硬件验证.md)。软件使用本地临时签名，更新或移动应用后可能需要重新添加权限。

## 导入 Windows 官方配置

0.7 起支持本型号官方 Windows JSON。先读取当前 USB 键盘，然后在“配置文件”页点击“导入配置”。应用会核对型号与整个默认布局，转换官方逻辑顺序的键位和颜色，处理绑定动作引用与单次键盘宏，并显示导入数量。导入只改变待写入配置，不自动写入键盘；失败时保留原编辑区。

支持普通键、修饰键组合、媒体键、12 个已验证灯效模式、109 个实体键的颜色，以及包含平衡按下／松开的单次键盘宏。官方的灯效列表索引和媒体动作索引会查表转换，不直接当作 USB 编码。

Fn、CHERRY 内部键、隐藏位置、未知灯效参数和系统参数保留当前配置。已有宏库保留，导入的绑定宏追加到库中；容量不足时拒绝导入。未绑定的 Windows 动作库不迁移，文本、鼠标与滚动、循环和固定间隔宏暂不支持。包含不支持绑定的文件会整份拒绝，不能跳过该键后悄悄导入其他内容。

导出使用 CherryMac JSON，不生成 Windows 官方格式。格式转换的依据与测试见[Windows 配置导入](Windows配置导入.md)。
