# CherryMac 使用说明

适用于 Mac 0.10.0 和 Web 0.4.0 按键写入测试版。开放 USB 有线键位写入、备份和读回核对；灯效与宏实体写入暂缓，完整复刻仍在进行。

## 先预览，或读取键盘

打开客户端或网页后，无需连接键盘即可预览编辑。正常单键为正方形，计算器与三个媒体按钮在右上角。

要读取当前配置，请用 USB 数据线连接并切换到有线模式。客户端点击“读取键盘”；网页使用 Chrome 或 Edge，点击“连接 USB 键盘”，在设备选择弹窗中选择 CHERRY。只有充电功能的线不能读取。

读取后会自动保存备份。如果读取或备份失败，页面会提示。读取不发送配置写命令。

## 按键功能

点选按键，再选择预设或自定义组合键，保存到编辑区。框选截图为 ⇧⌘4，刷新为 ⌘R。Fn 和 CHERRY 内部键保留内部功能。

计算器媒体键通常不会直接启动 macOS 计算器。客户端可以安装计算器快捷操作，再设置为 ⌃⌥⌘C；受限 USB 测试已成功启动系统计算器并恢复配置；当前可从按键页面写入该组合键；网页不能安装系统服务。服务是否生效也取决于前台应用的服务支持。

保存到编辑区后，点击“写入键位”（网页为“写入按键”），检查改动，松开全部按键，用鼠标确认。写入时不要使用键盘；网页需保持前台。程序先核对配置、保存并验证备份，再写入键位表，完整读回检查灯效与宏区是否保持原值。Fn、CHERRY 内部键、隐藏位置与宏绑定改动不允许写入。

## 灯效

灯效仅供编辑与导出，当前不写入键盘。

“内置灯效”设置模式、亮度、速度、方向和颜色，保存到编辑区。不同模式可能忽略部分选项。

“逐键配色”先选按键或区域，再选颜色与配色方式，点击“应用到所选键”。⌘ 点击可多选；也可选择 WASD、主键区、方向键、数字区或全部。选择“熄灭所选键”只改变这些位置的预览颜色。

网页版的 RGB 与强度位于“精细颜色”展开项。客户端可直接输入 RGB 或 HEX。内置模式的单色设置与逐键颜色选择独立。

逐键配色为静态，不支持每键独立动画。工程图展示编辑颜色，不模拟实体动画。

## 宏

宏仅供编辑与导出，当前不写入键盘。

添加按下、松开和延迟，每个按下必须有对应松开。保存宏，再分配到所选按键。可为所选按键选择指定次数（1–255）、按住持续或再次按键停止，再点击“分配到所选键”。导出会保存执行方式；绑定到同一个宏的不同按键可以分别设置方式。当前支持键盘事件，鼠标与滚动事件暂未支持。宏执行方式依据官方程序静态分析，实体执行、中止与持久化仍需后续验证。

客户端步骤文本示例：`A 按下 0`、`A 松开 50`，每步一行，数字为延迟毫秒。网页使用步骤列表编辑。

## 配置与备份

此页不展示键盘图。支持导入 CherryMac JSON，以及本型号的 Windows 官方配置；Windows 导入前先读取键盘。遇到不支持的绑定会拒绝整个导入，保留原编辑配置。

导出保存当前编辑区；撤销恢复读取时的配置，未连接时恢复演示配置。导入、导出与撤销都不会修改实体键盘。

客户端点击“恢复最近按键备份”，会重新读取设备并展示恢复改动，确认后只恢复键位表；也可打开自动备份、导入其他配置再写入键位。网页点击“查看本地备份”，导入后核对并写入按键。两端当前均不恢复灯效与宏。保留原浏览器与网址，避免清理网站数据。

## 设备与诊断

网页可导出排查资料，包含已有备份、当前编辑区和请求、回复、耗时、写入阶段与错误日志。文件仅下载到本地，不自动上传，可能包含宏内容；请自行选择是否分享。

客户端此页提供“打开操作日志”和 Mac 端适配设置入口。适配默认暂停，启用 F5 等软件映射需要应用持续运行及系统授权。

Win 锁、6 键／全键模式、回报率等官方设置还在核对协议。灯效异常根因、宏实体执行和无线使用尚未确认。计算器键在受限测试中已通过用户确认断电后的保留，新版两端的完整按键流程仍需实际验收。

写入失败后需重新读取；只有连接仍有效、数据变化仍符合本次范围且日志与按键释放检查通过时才尝试恢复。断线或超时不保证自动恢复成功。备份与操作日志自动保留，无需手工抓包。


## 扩展前缀备份

在 Mac 的“设备与诊断”点击“读取并保存扩展备份”，使用 USB 有线连接。程序读取两遍并比较，再保存到本机备份库并核对保存结果，成功后 Finder 会选中备份文件。若开启文本服务，会先停止服务再读取。关闭配置窗口会取消后续读取。读取不会改变编辑草稿或键盘配置。

两端“检查扩展备份文件”支持旧版0104静态格式，以及新版0102实测格式；可保存到各自的本机库、导出副本。网页版当前只处理已捕获文件，未开放直接扩展读取，因为浏览器接口不提供所需的USB版本身份。当前备份覆盖参数63、键位511、颜色511和宏3071字节，各区仍有一个末字节未捕获，不能用于完整恢复或接收器配对。


在 Mac 的“设备与诊断”点击“检查扩展捕获日志”，选择一次捕获的编号文件夹，可查看已接受读取数、最后阶段、失败原因及备份编号，或导出日志JSON。副本应保存在原日志文件夹以外，保留逐条事件。网页版同页的“扩展捕获日志”可检查这份JSON，不需要连接键盘。历史日志不会自动恢复配置，也不能证明当前键盘状态或断电保存。
