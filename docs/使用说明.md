# CherryMac 0.3 · 可点选键盘设置

为你通过蓝牙连接的 CHERRY MX 3.0S Pokemon-BT1 制作的 Mac 菜单栏软件。当前交付包适用于 Apple 芯片 Mac，macOS 13 或更新版本。

## 明天先做这几步

1. 从菜单栏「⌨︎」退出 CherryMac。将 CherryMac.app 移到「应用程序」，再打开。
2. 点击「输入监控权限」和「辅助功能权限」，在系统设置中为 **CherryMac** 开启这两项权限。授权 Codex、终端或测试进程不能代替给 CherryMac 授权。
3. 从菜单栏退出后重新打开。底部状态应显示输入监控、辅助功能已开启，替换已就绪。
4. 切换到浏览器，分别验证截屏键、计算器键和 F5。若键盘上的功能需要 Fn，请按原本的 Fn 组合。

本次打包启动验证确认：应用能运行并识别蓝牙键盘，但 **CherryMac 自身尚未获得这两项系统权限**，因此现在还不能执行实体按键适配。没有替你修改系统授权。

## 点图设置功能

点击键盘图上的按键，在右侧「按下后执行」中选择功能，再点击「保存设置」。小圆点表示已有设置，蓝色表示当前选中。默认设置如下：

| 实体按键 | 执行功能 | 生效范围 |
| --- | --- | --- |
| 截屏 / Print Screen | 框选区域截图 | 各软件 |
| 计算器 | 打开系统计算器 | 各软件 |
| F5 | ⌘R 刷新 | 支持的浏览器 |

还可以选择截图工具栏、查找、新建/关闭标签页、复制、粘贴、撤销和 Spotlight。选择「自定义快捷键…」后，勾选 ⌘、⇧、⌥、⌃，再选择主键。自定义组合需要至少一个修饰键。

勾选「仅在浏览器中生效」后，只在支持的浏览器处于前台时执行；其他软件保留原功能。在设置窗口前台不触发已配置动作，避免干扰编辑。截图、计算器和 Spotlight 可通过测试按钮验证；其他动作应保存后切换到目标软件，按实体键验证。

按住修饰键时保留原来的组合行为；普通按键长按不重复执行新增动作。取消设置时点击「恢复原功能」，只影响当前选中键。

## 原按键替换与兼容方式

默认使用底部的「替换原按键 · 避免重复输入」：对于已配置的普通键，通过这把 CHERRY 的输入信号与系统按键事件的精确时间、键码关联，确认来源后拦截原输入，只执行新动作。因此 F5 不会同时执行原 F5 和 ⌘R，字母键也不会同时输入原字符。

未设置的键、其他键盘、范围外的操作、修饰组合、不能确认来源的事件，全部保留原输入。软件不接管整把键盘，也不修改键盘固件或系统的持久按键映射。退出软件即停止适配。

计算器等非普通键采用兼容触发。这类键若本身已有系统行为，原行为可能仍会发生。

如果替换模式没有反应：先检查权限、前台软件范围，再尝试重新识别按键。仍无效时，可切换到「追加动作 · 旧版兼容方式」验证信号是否能收到。追加方式会同时保留原输入；只建议用于特殊键或 F 区。不同硬件/系统版本若不能精确关联普通按键事件，替换模式会保留原输入，不会凭键码猜测来源。

## 识别实体按键

选中图上的按键，点击「识别这个实体按键…」，在 15 秒内按一下实体键；需要 Fn 时按原组合。识别成功后选择功能并保存。已有配置的按键重新识别后，会更新其实体信号。

重复信号会提示冲突，不会悄悄覆盖另一键的设置。Fn 和灯光等键盘内部功能，若不向 Mac 发送信号，则无法识别。

键盘图为全尺寸 108 键布局示意，**不是精确测量的工程制图**。普通单键采用正方形；空格、Shift 等宽键和数字区双行键保留实物比例。右上角按你确认的布局排列计算器、上一曲、暂停、下一曲，分别位于 Num、/、×、− 上方。下方浏览器和 CHERRY 区是其他功能的设置入口。Ctrl、Win、Alt、Shift、Fn 和图上的 Caps Lock 暂不支持重新分配。

## 保存、备份和暂停

设置自动保存在本机。点击「导出配置…」可保存 JSON 备份；「导入配置…」会替换当前设置。导入前会检查格式、信号冲突和快捷键有效性，失败时保留现有设置。导入自己的新配置前，可先导出旧配置。

窗口右上角和菜单栏都有暂停开关。暂停或退出时，所有原按键继续正常输入。关闭设置窗口后仍在菜单栏运行。需要开机启动时，可手动添加到系统设置 → 通用 → 登录项。

## 兼容范围

- 当前精确匹配蓝牙设备的厂商编号 0x0687 和产品编号 0x00E9，识别名称为 MX 3.0S Pokemon-BT1。其他连接方式或不同硬件编号需要重新确认。
- 浏览器范围覆盖 Safari、Chrome、Edge、Firefox、Brave、Opera、Vivaldi、Arc、Zen，以及源码列出的部分测试版。其他浏览器可取消范围限制，但所配置动作会在各软件执行。
- 截图触发系统的 Shift–Command–4；拖动框选，Esc 取消，保存位置遵循 Mac 截图设置。
- 不联网、不持久记录打字内容。只保存设置和学习到的按键编号。输入来源匹配只使用内存中的有限事件记录。
- 首次升级保留 0.1 版本学习的截图、计算器信号和 0.2 版本的功能配置。
- 当前为本机临时签名版本，没有开发者公证。更新或移动应用后，系统可能要求重新添加权限条目。
