## 本轮宏接入

官方方式按每个绑定分别存储记录，单宏最多 762 个事件，总可访问容量 3071 字节；同一宏绑定多个键会重复占用，未绑定宏仅保存本地。容量按实际绑定计算，Windows 导出使用本地库索引，不能把硬件序号当作库索引。

写入计划使用最近实际读回基线，保留未发送的宏区尾部。名称资料采用版本化草稿记录，恢复同时核对键位、宏区、实际默认映射、库、绑定和播放方式。旧资料明确保持共享库方式；宏页可点击“启用扩展宏编辑”，仅转换草稿，核对后另行写入。新存储范围尚未做实机验证。

恢复记录现在携带与写入前硬件数据匹配的宏名称资料，恢复读回后再次核对；旧记录及资料缺失时仍支持原始硬件恢复。恢复入口保留扩展布局，避免没有名称缓存时回退到旧编码。产品宏写入同时要求草稿默认映射与最近实际读回一致；官方 JSON 导入采用读回基线的映射。此轮没有实机恢复或持久化验证。
