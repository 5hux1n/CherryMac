截至 2026-10-05，完整复刻尚未完成。当前本地产品预览为 Mac 0.32（build 34）与 PHP 0.29；独立灯效验收包为 Mac 0.1.9（build 10）与 PHP 0.1.13。四包源码均为 `e6ee6ad063a2cc4b469872c8d9b538df986ac488`，清单中的硬件验收状态为 `pending`。GitHub 公开下载的按键测试版仍为 Mac 0.12／PHP 0.6，不能把本地预览功能当作已公开发布功能。

本轮已把下文记录的默认草稿导入、恢复／撤回计划核对、事务日志与存储代码纳入四个新包。默认 USB 开发入口在这些包中关闭，没有完整恢复执行按钮；历史段落中的“当前包未更新”描述的是对应旧包状态。新包没有运行应用或硬件验收。

以下按[完整交付标准](移植验收目标.md)核对，源码、编译和模拟检查只证明相应离线范围，不能代替实体输出、视觉效果或断电保留。

上述包已经纳入两端“仅导入官方灯效”入口与 LightOpenFlag 草稿同步。它仅替换灯效草稿，保留已有键位、宏、文本与设备设置；见[灯效功能说明](灯效功能与验证.md)。这次仅编译和打包，没有运行测试或访问设备；旧包保留，普通版灯效写入仍未开放。

随后源码补齐“多媒体功能”选择：官方资源默认可见的 11 项均可点选，全部 18 项都能显示导入后的功能名称。此改动已纳入上述包；选择只改变编辑区，媒体动作在 Mac 的实际响应仍需核对，启动类动作不等于已实现 macOS 应用启动。

源码另外接入 [Mac 应用启动快捷操作](Mac应用启动.md)：计算器、Finder、邮件、音乐可分别生成系统服务并设置组合键草稿，由用户手动点击安装。网页仅设置相同键位；不依赖 CherryMac 后台监听。新增三种服务入口已纳入上述包，但尚未实际安装或触发。

源码已统一灯效页面的主按钮：普通版核对并导出计划，研究版进入独立备份、重新读取、确认写入与恢复流程。客户端主按钮不再调用旧灯效发送方法；网页计划导出不停止文本服务或关闭设备。此改动已打包，尚未运行或真机验证，普通版灯效发送仍未开放。

原生源码已接入独立灯效窗口的有效结果回传：按原计划／基线核对后更新读回，保留所有未发送草稿及原始 RGB；颜色变更标记按实际发送目标计算。失败、取消、拔线或计划不符时不接回。两端增量已打包，尚未运行。网页也已接入独立页结果回传，重新连接要求完整读回一致后采用新基线，保留全部草稿；回传消息本身不授权写入。

## 代码完成范围与接下来工作

主要按键、宏、文本编辑与执行流程，以及灯效编辑、受限写入和恢复流程已有代码。完整复刻的代码还没有全部完成：设备设置的本型号固件发送协议尚未确认，普通版灯效写入仍未接通，不能把这些缺口概括成“只剩测试”。

用户在 2026-10-05 明确更新为先完成全部可离线推进的开发，将所有真机测试放到最后。当前继续离线追踪官方设备设置与动态模块调用，并推进两端实现、整合、审查和打包；不启动产品窗口、不请求权限、不访问或写入键盘，也不重复已通过的检查。此前模块开发后立即实测的安排已被取代。确实依赖实机数据的缺项单独记录，完整交付目标保持不变。

恢复测试时，再集中核对宏与文本产品入口，随后单独核对灯效的外观、断电与恢复。设备设置须先取得本型号实际发送路径；工作区字段、窗口通知和主机 DLL 动作不能充当固件命令。用户关电确认与 USB 拔插记录只是断电流程证据，不是内部电源测量。
