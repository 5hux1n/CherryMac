# 当前功能与验收状态

截至 2026-10-05，完整复刻尚未完成。当前本地产品预览为 Mac 0.29（build 31）与 PHP 0.26；独立灯效验收包为 Mac 0.1.6（build 7）与 PHP 0.1.10。四包源码均为 `8a1ac4502f4c1009d5efc95b46ba55129161bdae`，清单中的硬件验收状态为 `pending`。GitHub 公开下载的按键测试版仍为 Mac 0.12／PHP 0.6，不能把本地预览功能当作已公开发布功能。

以下按[完整交付标准](移植验收目标.md)核对，源码、编译和模拟检查只证明相应离线范围，不能代替实体输出、视觉效果或断电保留。

上述包已经纳入两端“仅导入官方灯效”入口与 LightOpenFlag 草稿同步。它仅替换灯效草稿，保留已有键位、宏、文本与设备设置；见[灯效功能说明](灯效功能与验证.md)。这次仅编译和打包，没有运行测试或访问设备；旧包保留，普通版灯效写入仍未开放。

随后源码补齐“多媒体功能”选择：官方资源默认可见的 11 项均可点选，全部 18 项都能显示导入后的功能名称。此改动尚未纳入上述包；选择只改变编辑区，媒体动作在 Mac 的实际响应仍需核对，启动类动作不等于已实现 macOS 应用启动。

源码另外接入 [Mac 应用启动快捷操作](Mac应用启动.md)：计算器、Finder、邮件、音乐可分别生成系统服务并设置组合键草稿，由用户手动点击安装。网页仅设置相同键位；不依赖 CherryMac 后台监听。新增三种服务尚未实际安装、触发或纳入上述包。

源码已统一灯效页面的主按钮：普通版核对并导出计划，研究版进入独立备份、重新读取、确认写入与恢复流程。客户端主按钮不再调用旧灯效发送方法；网页计划导出不停止文本服务或关闭设备。此改动尚未打包、运行或真机验证，普通版灯效发送仍未开放。

## 代码完成范围与接下来工作

主要按键、宏、文本编辑与执行流程，以及灯效编辑、受限写入和恢复流程已有代码。完整复刻的代码还没有全部完成：设备设置的本型号固件发送协议尚未确认，普通版灯效写入仍未接通，不能把这些缺口概括成“只剩测试”。

用户在 2026-10-05 明确要求继续开发、暂不测试。当前继续离线追踪官方设备设置与动态模块调用；不启动产品窗口、不请求权限、不访问或写入键盘，也不重复已通过的检查。此前关于是否方便测试的询问已由这一安排取代。完整交付目标保持不变。

恢复测试时，再集中核对宏与文本产品入口，随后单独核对灯效的外观、断电与恢复。设备设置须先取得本型号实际发送路径；工作区字段、窗口通知和主机 DLL 动作不能充当固件命令。用户关电确认与 USB 拔插记录只是断电流程证据，不是内部电源测量。
