# 用键盘启动 Mac 应用

源码已接入计算器、Finder、邮件和音乐的 Mac 快捷操作。Finder／邮件／音乐与新的选择入口尚未纳入当前 Mac 0.29／PHP 0.26 预览包，未做实际安装或实体按键验收。

| 启动功能 | 键盘输出 | 对应应用 |
| --- | --- | --- |
| 计算器 | ⌃⌥⌘C | 系统计算器 |
| 我的电脑／Finder | ⌃⌥⌘F | Finder |
| 邮件 | ⌃⌥⌘M | 系统邮件 |
| 媒体播放器／音乐 | ⌃⌥⌘P | 系统音乐 |

客户端“按键功能”中选择对应的 Mac 启动功能，再点击“安装并设置 Mac 启动”。也可以在“多媒体功能”选择计算器、我的电脑、邮件或媒体播放器后使用该按钮。安装成功后，对应组合键进入当前键位草稿；核对后通过原按键写入入口保存到键盘。安装本身不写键盘。

网页提供同样的组合键预设，但浏览器不能安装 macOS 系统服务。先在客户端安装对应快捷操作，随后可以用网页编辑及写入相同键位。既有计算器安装按钮与服务标识保留。

应用启动由 Automator 快捷操作与系统“服务”菜单执行。CherryMac 不需要留在后台监听这些组合键。计算机仍需要保留安装的系统快捷操作；仅把组合键写入键盘，不能让键盘自行运行 Mac 应用。服务是否在目标应用中响应、实体释放及断电保留均待后续统一核对。

安装只涉及所选快捷操作。目标应用或系统动作缺失时拒绝；同名 workflow 若不是对应 CherryMac 标识则拒绝覆盖。已存系统服务偏好出现同一快捷键字符串时拒绝安装，不修改服务或键位；此检查不代表已穷尽所有应用和系统快捷键冲突。其他系统服务的偏好继续保留。安装过程中保存或注册失败会显示错误，键位草稿只在安装成功后更新；部分系统文件可能已保存，不能把错误提示理解为安装过程已完整回滚。

本轮只读取系统应用的 Info.plist 核对标识，并做 Swift 类型及 PHP 语法检查，没有执行安装、注册服务、启动应用、读取输入或访问键盘。当前仍按用户要求暂不测试。
