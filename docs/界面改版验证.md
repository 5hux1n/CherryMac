# Mac 0.8.0 / Web 0.2.0 界面改版验证

本版交付五个功能页面和两个灯效子页面，属于界面预览与 USB 只读版。完整官方功能移植和真实灯效故障修复尚未完成。

## 已核对并修正

- 客户端与网页菜单均为键位、灯效、宏、配置与备份、设备与诊断。配置与诊断隐藏键盘工程图，保留编辑配置。
- 灯效分为内置模式与逐键配色。内置单色采用独立颜色控件，修改时不替换逐键起点颜色。原生自测与浏览器操作覆盖这一行为。
- 网页原先进入灯效页会重新加载参数，丢失尚未保存的表单输入；现仅在读取、导入或明确的配置修改后同步。浏览器检查切换菜单保留亮度输入。
- 网页侧栏继承了旧页头的自动外边距，导致导航在高页面上居中；已去掉继承的外边距，截图核对菜单位于顶部。
- 网页普通键原先受百分比边框尺寸影响，宽高有轻微误差；已采用正方形比例。浏览器检查实际普通键宽高误差小于 0.1 像素。
- 真实配置写入继续停用。网页原有按钮、业务入口与底层保护保留；客户端新增 UI 入口与 `CherryUSB.exchange` 查询白名单，拒绝写命令、未知命令、越界、非零标志、携带数据和校验不符的查询。内部写入算法仅由内存模拟测试调用，不代表可对实物写入。
- README 与使用说明已按当前版本改写，移除让用户操作已停用写入功能的步骤。
