# 灯效、宏和板载配置：当前进展

官方 CHERRY UTILITY 说明确认：提供灯光控制、宏、文本、多媒体及按键分配，并可把个性化配置存储在支持设备中。官方支持列表包含 MX 3.0S RGB Wireless 的皮卡丘及喷火龙版本。Windows 软件不是单纯的系统快捷键工具。

- 官方说明：https://www.cherry.cn/cherryutility.html
- 支持型号：https://www.cherry.cn/support.html
- 官方安装包：https://file.cherry.cn/Driver%20Software/CHERRY%20Utility%20Setup20260410_2.3.28.7.exe

## 已确认的设备接口

本机只读检查识别到 `MX 3.0S Pokemon-BT1`，连接方式为 Bluetooth Low Energy，VID `0687`、PID `00E9`。报告描述符包含：

- 厂商页 `FF1C`、用途 `0092`，报告 ID 4，输入/输出报告共 64 字节。
- 厂商页 `FF00`，报告 ID 9，Feature 报告共 30 字节。
- 厂商页 `FF00`，报告 ID 12，输出报告共 64 字节。

说明蓝牙连接也有厂商接口，但描述符不能说明每条命令的含义，不能据此直接写入灯效或板载宏。检查仅读取设备信息和报告描述符，没有发送控制、擦除或配置写入命令。

## 协议线索与限制

OpenRGB 的 CHERRY 控制器使用报告 ID 4 和 64 字节包，和上述接口形态相似。但是现有支持设备与本机 VID/PID 不同，尚未验证无线宝可梦版本的命令、校验方式和持久化步骤。不能把有线型号的指令直接当成这把键盘的指令。

源码参考：https://github.com/CalcProgrammer1/OpenRGB/tree/master/Controllers/CherryKeyboardController

## 软件实际能力

CherryMac 0.3 的键位配置保存在 Mac 上，需软件运行及系统权限；尚不支持灯效、宏序列或配置写入键盘。截图、计算器、浏览器 F5 和自定义快捷键属于 Mac 端执行。

后续必须确认这款设备的配置协议，才能实现真正的硬件功能。若官方软件静态分析无法确认，需通过 Windows 上的官方软件记录 USB 通信，对比一次改键、一次灯效调整与一次保存的请求。还要验证配置是否在断电、换电脑后保留，以及官方配置是否必须使用 USB 连接。以上待验证事项暂不需要现在回答。

## 开源项目检索（2026-10-01）

用户已确认 Windows 官方软件要求 USB 连接。后续优先调查 USB 协议；当前没有转接头，不要求立即连接设备。

1. **cherryrgb-rs**：https://github.com/skraus-dev/cherryrgb-rs
   提供动画、亮度、单键颜色和颜色配置文件。当前源码的 CI 包含 Apple Silicon 与 Intel macOS 构建。兼容表验证的是部分有线 CHERRY 键盘，没有无线宝可梦款；README 明确把独立改键列为缺失功能。源码有 GetKeymap 查询，但这不能当作可写入键位或板载宏。已下载源码到工作目录供协议研究，未运行设备控制命令。
2. **OpenRGB**：https://openrgb.org/
   有 macOS 版本与 CHERRY RGB 控制器。当前所查 CHERRY 检测源码没有无线 3.0S 注册项。无线型号的设备申请 https://gitlab.com/CalcProgrammer1/OpenRGB/-/issues/4564 提供 USB 抓包线索：有线 VID 046A/PID 00E3，接收器 VID 046A/PID 00EA；静态红绿蓝、亮度、模式、速度等抓包均在有线模式取得。这是最贴近无线型号的线索，但不是已经完成支持的证明，也不是宝可梦版本协议已确认。
3. **cherrymxboard30s-rgb**：https://github.com/luv4bytes/cherrymxboard30s-rgb
   基于官方 USB 通信逆向的 Linux 灯效工具。已于 2023 年归档，作者建议使用 cherryrgb-rs。没有证据表明它覆盖无线宝可梦款的板载改键与宏。

本次没有找到已明确支持本机无线宝可梦版本、并完整实现板载改键、宏和保存的开源替代软件。灯效协议已有可研究代码；板载映射和持久化仍需单独确认。
