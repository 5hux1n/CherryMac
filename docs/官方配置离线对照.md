# 官方配置离线对照

以下入口供开发与诊断使用，只处理本地文件，不连接键盘。当前导出只替换官方模板中的键位与宏；灯效、设备设置和其他字段继续沿用模板，不代表已完成全部官方配置导出。

```sh
CherryMac --export-windows-keys-macros 输出.json --profile CherryMac配置.json --template 官方模板.json
CherryMac --convert-windows-profile 导入结果.json --profile 输出.json --baseline CherryMac备份.json
node Web/tests/native-windows-roundtrip.mjs /绝对路径/CherryMac
```

导出禁止覆盖源配置或模板，转换验证失败时不生成输出。未知宏事件字段无法可靠关联到修改后的事件时拒绝导出，避免静默丢失资料。

跨端检查使用合成配置，覆盖计次、按住和切换三种绑定、鼠标与修饰键事件、实际延迟、未知宏字段、七项设备设置字段，以及普通组合键。追加跨端检查覆盖未绑定宏、共用计次绑定、内部文本动作索引重排，以及同名宏附加字段不一致时的双端拒绝。先比较两端官方 JSON 语义内容，再分别导入并逐字节比较 deviceInfo、parameters、keymap、colors、macroData；也比较宏库、绑定、播放模式和保留的模板。临时测试文件结束后删除。

这些检查不能证明宏在实体键盘上执行、断电保留或恢复成功，也不证明灯效、设备设置已经支持实物写入。后续仍须逐项真机验收。
