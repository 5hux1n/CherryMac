# 当前移植目标与交付标准

用户于 2026-10-02 明确要求：针对 CHERRY MX 3.0S Pokémon Wireless，逆向其 Windows 官方配置软件，复刻功能至 Mac 客户端和无需构建的 PHP 网页版；实现后自行核对、校验、审查代码，再打包交付。客户端和网页按功能分页面，保持简单易用。

这份文件是持续工作的验收标准。当前没有达到“完整移植完成”，不以预览包、协议推测或模拟测试通过替代实机验收。

## 功能范围

| 功能 | 需要完成的验收 |
| --- | --- |
| 键位 | 点选工程图、普通键与组合键、媒体键、禁用；核对实体输出与修饰键释放 |
| 内置灯效 | 对照该型号在官方软件实际可选的模式、亮度、速度、方向与颜色选项；核对外观 |
| 逐键配色 | 每个可见实体键的 RGB、单键熄灭、多选与批量设置；隐藏位置保留 |
| 宏 | 核对官方支持的事件类型、延迟和执行模式；逐项移植并验证结束与中止，不猜测循环行为 |
| 配置 | 官方 JSON 与 CherryMac 格式的导入导出、完整备份、故障恢复；未知内容明确保留或拒绝 |
| 设备设置 | 官方界面中的 Win 锁、6 键／全键模式、回报率与重复设置；区分固件设置和 Windows 系统设置 |
| 持久化 | 写入成功后断电重连，核对配置；再核对蓝牙／接收器使用时的效果 |
| Mac 适配 | 系统计算器、框选截图、刷新；明确需要 macOS 服务或持续运行软件的功能 |
| 日志 | 记录实际请求、回复、耗时、错误与写入阶段，确保能分析真实失败过程 |

官方软件支持其他型号、Windows 路径与系统设置的能力，不能自动视作本键盘的固件能力。固件升级、恢复出厂等操作需独立确认协议和恢复条件。

## 界面与交付

- 客户端与网页使用一致的功能导航：键位、灯效、宏、配置与备份、设备与诊断。
- 灯效拆分为内置模式和逐键配色，RGB 与其他精细选项按需要展开。
- 配置与诊断页面无需重复展示完整键盘；编辑页面保留按键上下文，切换页面保留草稿。
- 正常单键保持正方形，右上角计算器与三个媒体键位置正确；检查窄窗口、深色和键盘导航。
- 代码审查需核对型号分支、参数边界、隐藏数据、故障中止与恢复、隐私和导入兼容；审查结论有可重复的测试支撑。
- 最终交付可直接打开的 `.app` 与 PHP ZIP，并提供一致的版本、校验值、功能状态和使用说明。

## 当前阻碍与进展

旧版网页发生过实物灯效故障，根因仍未确认。已用用户提供的真实备份运行旧代码的离线复现，修正未知灯效参数重发校验和逐包等待，但未复现物理熄灯／无法识别。客户端和网页全部写入继续停用。

已有部分键位与灯效读写实测，宏存储与绑定读回实测。2026-10-02 计算器键受限实机测试完成新映射、按下／松开、系统计算器启动、用户确认断电后的保留以及恢复完整流程；证据范围见[计算器键实机验证](计算器键实机验证.md)。普通 App／网页写入仍停用。其他键位、无线保留、实体宏执行及恢复实际通信失败仍待确认。不把不同型号的代码分支直接套用。

当前用户要求优先完成按键修改写入与断电保留，暂不进行宏与灯效的实物写入或功能验证。相关写入限制继续保留。
