macOS · 按键写入测试版

让 CHERRY 键盘，更贴合你的 Mac。

为 CHERRY MX 3.0S 宝可梦无线键盘提供 Mac 客户端与 PHP 网页版。点选按键，编辑快捷键、灯光和宏，保存或迁移配置。

下载 Mac 客户端 ↗阅读项目说明 ↗

当前支持 USB 按键写入、备份和读回核对。灯效与宏实体写入暂缓，完整 Windows 功能复刻仍在推进。

项目能做什么

按键与快捷键

设置组合键、媒体键和禁用按键；提供独立的 Mac 端按键适配功能。

灯光与宏编辑

编辑内置灯效、逐键静态颜色和键盘宏，修改保留在编辑区。

配置与备份

导入配置、导出 JSON，并在读取设备配置后保留自动备份。

开始使用

  1. 需要 macOS 13 或更新版本；当前下载包面向 Apple Silicon，Intel 尚未验证。
  2. 下载并解压，将 CherryMac.app 放入应用程序。通过 USB 有线模式读取设备配置。
  3. 点选按键、保存编辑，再确认写入。PHP 网页版需单独在本地或 PHP 主机运行。
