# 按键产品流程实机验收

2026-10-03。本记录针对当前客户端的实际编辑和写入方法，不替代已有计算器组合键、系统服务和用户确认断电保留的[历史实机证据](计算器键实机验证.md)。宏和灯效实体写入继续暂缓。

## 已获得的证据

本轮受控测试调用 `HardwareWindowController.stageKey` 与 `performKeyWrite`，后者使用正式 `CherryUSB.applyKeymap`。只临时修改计算器槽位 102，将原记录 `30 92 01` 改成普通 B 键 `20 00 05`。

- 写入七个标准 54 字节键位分块，完整读回一致。
- 等待 180 秒未收到实体按键事件，随后通过同一产品入口恢复原键位；恢复也发送七个标准分块，完整读回一致。
- 两次操作日志均为 complete，changedSlots 仅为 102；未发送灯效、宏或其他修改命令。实测最短分块起始间隔分别为约 2.27 秒和 2.335 秒。
- 恢复后另开 USB 会话读取，键位、灯效参数、RGB、宏区和设备信息均与原始备份一致。计算器恢复为 `30 92 01`。

因此本轮证明实际产品写入、超时恢复、独立读回与自动日志链路可运行。没有收到实体按下／松开，不标记普通键、组合键、媒体键或禁用功能通过；也没有新增断电保留证据。网页产品流程仍需独立实机验收。

首次预检曾将备份采集时间纳入相等比较，在写入前误报配置变化；已改为比较实际配置字段，并增加离线回归检查。正式产品写入方法原本就逐字段比较，不受此测试工具问题影响。

## 后续测试流程

研究工具先只读核对并备份，显示“开始四项按键测试”；等待点击时不写入、不计时。开始后依次将计算器键设为普通 B、计算器组合键、上一曲和禁用，再恢复原始记录。

前三项监听该 USB 键盘的真实 HID 按下与松开；不拦截、不合成输入。禁用阶段需要用户按过实体键后点击确认，因为“没有输出”无法独立证明用户确实按过。恢复后再次核对原始实体输出及独立读回。取消或未完成不会标记全部通过。

研究工具不编入普通发布 App。构建命令只生成工具并运行离线自测，不自动访问键盘：

```sh
bash Source/build-product-test.sh /absolute/path/CherryMacProductTest
```

实机运行需显式提供刚核对的完整备份及独立日志目录：

```sh
/absolute/path/CherryMacProductTest --product-key-test \
  --baseline /absolute/path/current-backup.json \
  --test-dir /absolute/path/new-test-directory
```

原始配置和逐条通信日志保留在本机，不提交公开仓库。此次已结束的记录目录名为 `ProductKeys-20261003-0110`，包含 before、目标、读回、恢复、独立读取与 test-log 文件；产品操作日志存入客户端 HardwareLogs 目录。
