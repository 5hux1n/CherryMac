## 后续测试流程

研究工具先只读核对并备份，显示“开始四项按键测试”；等待点击时不写入、不计时。开始后依次将计算器键设为普通 B、计算器组合键、上一曲和禁用，再恢复原始记录。

前三项监听该 USB 键盘的真实 HID 按下与松开；不拦截、不合成输入。禁用阶段需要用户按过实体键后点击确认，因为“没有输出”无法独立证明用户确实按过。恢复后再次核对原始实体输出及独立读回。取消或未完成不会标记全部通过。

研究工具不编入普通发布 App。构建命令只生成工具并运行离线自测，不自动访问键盘：


