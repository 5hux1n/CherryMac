# 宏编辑预览版发布

Mac 0.12.0（构建 13，Apple Silicon，macOS 13+）与 Web 0.6.0。完整官方功能移植尚未完成。

新增宏录制（三种间隔）、复制／清空、步骤四种排序、未绑定宏导入、来源动作身份与重命名后绑定保留。官方格式键位／宏导出为离线开发入口，灯效与设备设置沿用模板，尚未提供完整官方配置导出按钮。

产品仅开放已限定范围的按键写入。宏、灯效与设备设置实物写入仍关闭；独立研究 App 正在等待宏首次实体写入，尚无本轮宏执行或断电保留通过证据。旧研究 App 没有被替换，新下载包不包含研究测试入口。

验证：正常产品构建 17 组自测、临时本地签名验证和 plist 检查通过；打包后的产品二进制与网页官方文件转换对照通过。Chrome 界面检查通过，包括来源关联保存、排序错误拒绝、播放模式、109 方形键位、窄屏布局、仅模拟七包普通键位写入和自动备份／日志，无页面错误。以上未访问实体宏或灯效。PHP 语法检查、网页 13 项部署文件压缩校验和相对模块依赖／版本检查通过。

Mac 使用临时本地签名，未 Apple 公证。网页解压即可使用 PHP 启动，运行时不需要 Node 或构建工具。旧网页关闭后重新打开。
