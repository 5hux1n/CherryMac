# CherryMac 网页版 0.6.0：按键写入测试版

为 CHERRY MX 3.0S 宝可梦无线键盘提供点选设置、USB 键位写入、备份和自动日志。无需构建，部署只需要 PHP。**完整移植尚未完成；灯效与宏实体写入暂缓。** 旧版 0.1.0 曾发生灯效故障，请关闭旧页面，不再用旧版写入。

## 在线使用

打开 [CherryMac 键盘配置](https://cherrymac.goforit.si/app/)，使用 Chrome 或 Edge 直接编辑配置、连接 USB 键盘。网页由原有 PHP 模板在构建时生成静态文件，运行时无需 PHP。所有设备操作仍需浏览器授权和页面确认。

推送 `Web/` 更新后，GitHub Actions 自动构建并发布真实网页应用。静态构建命令：`python3 Web/build-static.py`。未设置开发预览环境变量时沿用源码默认功能开关。

## 打开或部署

也可直接打开 [Cloudflare 在线开发预览](https://cherrymac.goforit.si/app/)，不用下载或运行 PHP。当前在线版包含宏和文本开发功能，尚待统一真机验收；灯效写入未开放。线上与本地网址的备份分别存储。[在线版与更新说明](../docs/Cloudflare在线版.md)

在解压目录运行：

```sh
php -S 127.0.0.1:8768 -t .
```

用 Chrome 或 Edge 打开 <http://localhost:8768/>。也可双击 `start.command`；终端按 Control+C 停止服务。

上传 `index.php` 与整个 `assets` 到 HTTPS 的 PHP 网站可直接运行，不需要 Composer、npm、构建或服务器数据库。PHP 内置服务用于本机。已验证 PHP 8.5 输出与 JavaScript MIME 类型。模块带 0.6.0 版本标记；旧页面不会自动更新，需关闭后重新打开。

## 设置按键

1. 连接 USB 数据线、切换有线模式，点击“连接 USB 键盘”，在浏览器弹窗中选择 CHERRY。
2. 自动读取完整配置、保存备份后，在“按键功能”点选键位，选择功能或编辑组合键。
3. 点击“写入按键”，检查改动，松开全部按键，用鼠标确认；保持页面前台，完成前不要使用键盘。
4. 页面先重新核对配置并校验本地备份，再分块写入键位表、读回核对完整配置。

普通键、组合键、媒体键和禁用支持编辑及受限写入。Fn、CHERRY 内部键、隐藏位置以及新增／移除／修改宏绑定不允许写入。本版只发送键位表；灯效、颜色、宏区与未知数据保留原值。读取、导入及编辑均不会自动写入。

计算器组合键 ⌃⌥⌘C 需要先由 Mac 客户端安装系统快捷操作；网页无法安装 macOS 服务。无线写入仍未确认。[Chrome WebHID 文档](https://developer.chrome.com/docs/capabilities/hid)

## 功能菜单

按键功能、灯效、宏、配置与备份、设备与诊断各占一个页面。灯效分为内置模式和逐键配色；RGB 与强度按需展开。宏执行方式可设为指定次数（1–255）、按住持续或再次按键停止，并可导入相应的 Windows 键盘宏。灯效和宏可编辑、导出，当前不能写入实体键盘。逐键配色为静态，不支持逐键独立动画。

## 恢复按键与日志

“配置与备份 → 查看本地备份”可下载备份或导入编辑区；导入后自动进入按键页，核对并点击“写入按键”只恢复键位表。Windows 官方 JSON 导入前先读取键盘。宏绑定等不支持的改动会被拒绝。

写入错误后重新连接、读取，再决定恢复。连接仍有效时，仅在新读取的全部配置符合原表／目标表范围、按键已松开且日志可保存的条件下尝试恢复原键位；断线、超时或未知变化时停止写入，保留备份。自动恢复不保证在实际设备故障中成功。

备份与日志仅保存在当前浏览器、当前网址的本地数据库，刷新后可导出。切换浏览器或网址不会携带旧备份，清理网站数据会删除它们。

“设备与诊断 → 导出排查资料”下载浏览器信息、备份、编辑区、实际请求／回复／耗时、错误和写入阶段。写入前要求日志持久化成功；失败会停止后续写包。文件包含按键或宏内容，保存在你的电脑，不自动上传。新日志不能补出旧版故障时未记录的包。

## 验证与调查状态

26 项网页核心测试和 Chrome 完整操作测试已通过，设备均为模拟 WebHID。界面测试覆盖导航、正方形键帽、深色、窄屏、按键写入、灯效草稿保留、备份与日志导出。计算器键已有原生受限程序的实际 USB 与用户确认断电保留结果，**网页新写入流程尚需实机验收**。[本版验证](https://github.com/5hux1n/CherryMac/blob/main/docs/按键写入版验证.md)

旧版灯效故障根因仍未确认。离线复现可重现快速连续发包、未知参数重发及注入通信错误后的部分配置，不能模拟真实熄灯或系统识别异常。[调查记录](https://github.com/5hux1n/CherryMac/blob/main/docs/网页版灯效异常排查.md)

## 开发验证

仅完整 Git 仓库包含测试脚本；部署 ZIP 不包含测试及依赖。Node 和 Playwright 仅用于开发，运行 PHP 页面不需要安装它们。

```sh
node --test tests/core.test.mjs
php -l index.php
node tests/replay-diagnostics.mjs CherryMac-diagnostics.json
node tests/reproduce-legacy.mjs
node tests/native-profile-parity.mjs
```

回放脚本只分析已有记录；旧版复现脚本从固定历史提交载入实现，操作内存模拟设备。可附排查 JSON 和 Windows 恢复 JSON，不访问真实硬件。输出明确区分注入故障、物理故障未复现及当前非键位写入零操作。

可选安装开发用 Playwright 后运行 `node tests/browser-keymap.mjs`；默认使用本机 Chrome 和 `http://127.0.0.1:8768/`，可通过 `CHERRY_CHROME`、`CHERRY_TEST_URL` 与 `CHERRY_TEST_ARTIFACTS` 调整。输出截图与模拟诊断文件，不请求实体设备。

原生／网页配置一致性测试需先在 Mac 构建客户端，可将二进制路径作为参数传入。它只调用文件转换入口，不访问键盘。

宏页面支持键盘与鼠标左、右、中、前进、后退按钮的按下／松开编辑，Windows 宏导入会保留固定间隔选项与原事件延迟。滚轮与文本动作仍在移植；本版宏仅保存到配置文件，实体写入暂缓。

## 0.6 新增

宏页支持实际间隔、固定间隔和忽略间隔录制、复制、清空及步骤排序。Windows 导入保留未绑定宏、播放方式与官方来源记录，编辑改名后继续保留来源关联。所有宏改动目前保存到编辑区／配置文件；实体宏写入仍须研究流程验收。官方格式键位／宏导出当前是开发用转换入口，尚未作为完整配置导出按钮开放。


## 文本安装开发预览（源码）

当前源码可设置 `CHERRY_TEXT_PRODUCT=1` 启动 PHP，显示独立“文本”菜单；已有下载包尚未更新。例如在网页目录运行：

```sh
CHERRY_TEXT_PRODUCT=1 php -S 127.0.0.1:8768 -t .
```

选择本型号 Windows 官方 JSON，连接并读取键盘后，可点击“编辑文本绑定”选择按键、填写名称和多行文本。普通配置也能建立第一条文本绑定；采用后仅形成草稿。解除绑定会在下一次确认安装时恢复官方默认按键功能。准备安装后核对实体键再确认。文本定义先保存为本地版本记录，完整读回通过后才设为当前配置；失败保留原定义。可恢复最近安装、载入已保存定义及导出 JSON 和恢复记录。记录包含文本内容，请在清理网站数据前自行保存。可导入新版 Mac 客户端或网页版导出的文本恢复记录（最多 8 MB），适用于没有文本记录的新浏览器环境。相同记录可重复导入，已有不同记录不会被覆盖。客户端“文本”页也提供同格式的导入和导出。导入不会写入键盘或启动文本服务，恢复时仍需连接键盘并单独确认。

浏览器跨应用输入由 Mac 客户端执行。在客户端“文本”页点击“网页联动”，开启并复制联动码，粘贴到网页后点击“连接 Mac 服务”。安装并保存相同配置后，点击“启用 Mac 文本服务”；网页会先释放 USB，再把定义交给客户端，无需手动搬 JSON。客户端需要辅助功能权限，且配置窗口保持开启。

联动码仅本次客户端运行有效，存于当前标签页的会话数据，刷新后仍先核对服务；不会写入普通本地存储或 Cookie。网页配置操作和宏录制前等待客户端停止服务、释放 USB，联系失败时不开始配置操作。关闭网页会请求解除；未收到后续心跳超过两分钟时，客户端停止网页启动的文本服务。浏览器如询问本机网络访问，需要允许当前网页连接 CherryMac。[Chrome 的本机网络访问说明](https://developer.chrome.com/blog/local-network-access)

当前联动已通过本机 HTTP 与模拟执行器检查，尚未启动真实文本服务；两端文本真机验收仍未进行，不计作完整功能已验证。已有下载包尚未包含此增量。

在“配置与备份”点击“检查默认配置操作记录”，可离线检查 CherryMac 默认配置事务 JSON，并导出原始备份和分析资料；无需连接键盘。记录有完整、可识别的读回时才能另行导出撤回计划。备份包含原始宏区，不补造宏名称；导入只载入草稿。记录读回不是当前键盘状态，也不能证明实体输出或断电保留；实际恢复仍需重新读取和核对。完整恢复默认写入尚未开放。
