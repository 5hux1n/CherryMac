# CherryMac 网页版

在浏览器里点选 CHERRY MX 3.0S Pokémon Wireless 的按键，调整快捷键、灯效和单次键盘宏，通过 USB 配置键盘。

这是 **PHP + 原生 JavaScript** 的开发预览版。上传文件就能使用，不需要 Composer、npm、打包构建或数据库服务。PHP 只提供网页，USB 通信与文件处理在你的浏览器中完成；配置不会上传到服务器。

![逐键灯光配色预览](../docs/网页版预览.png)

## 在自己的 Mac 上打开

电脑需要已安装 PHP。在本目录运行：

```sh
php -S 127.0.0.1:8768 -t .
```

用 **Chrome 或 Edge** 打开 <http://localhost:8768/>。Mac 用户也可以双击 `start.command` 启动；终端按 Control+C 停止服务。PHP 内置服务用于本机预览，不用于公网部署。

## 放到 PHP 网站

把 `index.php` 和整个 `assets` 目录原样上传到 PHP 网站的同一目录，用 **HTTPS** 打开 `index.php` 即可。已验证 PHP 8.5 的页面输出，入口只使用标准 PHP HTTP 头功能，没有扩展依赖。服务器需把 `.js` 文件作为 JavaScript 提供。

PHP 网站可以放在服务器上，键盘应连接到**打开网页的那台电脑**。服务器不能替你访问本机 USB。普通 HTTP 网站、直接双击本地 PHP 文件、Safari 和 Firefox 都不适用于连接功能；不支持 WebHID 时仍可编辑演示配置。

## 第一次配置

1. 用 USB 数据线连接键盘，切换到有线模式。
2. 点击“连接 USB 键盘”，在浏览器的设备选择框中选择 CHERRY。页面会读取完整配置，并在本地保存备份，连接不会自动写入。
3. 点选键位并设置功能；或者进入“灯光配色”，选择多个键并配色。编辑宏时先保存宏，再分配到按键。
4. 检查右侧待写入内容，可以选择仅写入键位与宏、仅写入灯光，或者全部写入。
5. **松开全部按键，用鼠标确认。** 写入期间不要按键，保持网页在前台。完成后会读回键位、灯效、颜色和宏存储核对。

普通单键为正方形。计算器、上一曲、播放／暂停、下一曲位于 Num、/、×、− 上方。Fn、CHERRY 内部功能键和隐藏位置保留原值。

## 能设置什么

| 功能 | 可用设置 |
| --- | --- |
| 键位 | 框选截图、⌘R 刷新、自定义组合键、媒体控制、禁用 |
| 逐键灯光 | RGB、HEX、颜色强度、批量配色、横向／纵向渐变、静态彩虹、皮卡丘／喷火龙配色、单键熄灭 |
| 内置灯效 | 12 种模式、全局亮度、速度、方向和单色／彩虹选项 |
| 宏 | 键盘按下、松开和逐步延迟，执行一次；最多 32 个宏，共用 3071 字节 |
| 配置 | CherryMac JSON 导入导出、本型号 Windows 官方 JSON 导入、本地备份下载与导入 |

刷新预设会让实体键输出 ⌘R，适用于所有应用。若希望仅在浏览器里启用 F5，请使用原生 App 的 Mac 端适配。网页不能在所有应用中监听并转换按键。

macOS 通常不会用计算器媒体键打开系统计算器。另一方案是先在 CherryMac App 中安装计算器快捷操作，再用网页将键设为 ⌃⌥⌘C；完整实体启动效果仍待验证。网页不能安装 macOS 服务或直接让硬件启动任意应用。

Windows JSON 导入前需要读取完整配置。支持普通键、快捷键、媒体键、逐键 RGB 和单次键盘宏；不支持的绑定会拒绝整个导入。文本、鼠标、循环和固定间隔宏暂不迁移，未绑定动作库不迁移。导入和导出都不会自动写入。

## 备份与恢复

读取后及每次写入前，将完整配置保存到浏览器 IndexedDB。备份存储失败会阻止写入。在“配置文件 → 查看本地备份”中可以下载 JSON，也可以导入编辑区，再手动写入恢复。

备份与网站地址、浏览器及用户配置关联；改用另一个浏览器或网站不会自动带上备份。**建议下载到电脑保存**，清理网站数据会删除本地备份。

写后校验失败时，只有连接仍有效、页面仍在前台且松键确认有效，才尝试恢复原配置。USB 超时、无效回复和断线会关闭会话，避免重发可能已经执行的命令。此时请重新连接、读取实际配置，再导入写入前备份恢复。

浏览器无法读取受保护的普通键盘报告，只能检查本页面内的按键事件；因此松开全部按键必须由你实际确认。切走页面、按住按键或断线会停止后续写入，可能留下部分修改，届时按上面的流程恢复。

## 当前验证范围

网页版已通过 17 项离线协议与故障测试，以及 Chrome 页面交互和模拟 WebHID 设备的读写、备份测试。这些测试不连接或修改实体键盘。

底层 USB 协议来自原生 App 已完成的实物读写研究。**网页版的浏览器授权与实体 USB 写入仍待实测**，不能将模拟测试当成实物通过。宏实体触发、内置动画外观、断电与切换连接后的配置保留仍待验证。当前只实现 USB 写入，蓝牙和无线接收器写入未确认。

浏览器接口与保护规则见 [Chrome WebHID 文档](https://developer.chrome.com/docs/capabilities/hid)。无需浏览器实验开关，也不会绕过普通键盘／鼠标的保护。

## 开发验证

仅开发自测需要 Node，不影响 PHP 部署或用户使用：

```sh
node --test tests/core.test.mjs
php -l index.php
```

`package.json` 仅指定测试时 JavaScript 模块类型，没有依赖和构建步骤。部署只需要 `index.php`、`assets`，不需要 `tests` 或 `package.json`。
