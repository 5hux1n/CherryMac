# CherryMac 网页版 0.1.1：USB 只读排查版

**0.1.0 灯效写入曾导致实际键盘异常，已撤回公开下载。当前停用全部 USB 写入。** 请关闭旧版页面，再打开新版；不要用旧版重复测试。已恢复正常的键盘请保持当前设置。

保留键盘图、快捷键与逐键灯光编辑、宏编辑、配置导入导出、已有备份下载和本地排查资料导出。编辑与导入只改变网页预览，不能修改或恢复实体键盘。

## 在自己的 Mac 上打开

电脑已安装 PHP 时，在此目录运行：

```sh
php -S 127.0.0.1:8768 -t .
```

用 Chrome 或 Edge 打开 <http://localhost:8768/>。也可双击 `start.command`；终端按 Control+C 停止服务。

上传 `index.php` 与整个 `assets` 到 HTTPS 的 PHP 网站可直接运行，不需要 Composer、npm、构建或服务器数据库。PHP 内置服务只用于本机预览。已验证 PHP 8.5 页面输出与 JavaScript MIME 类型。

新版入口与模块带 0.1.1 版本标记，减少加载旧脚本的问题。已经打开的旧页面不会自动更新，必须关闭后重新打开。

## 读取与排查资料

“连接 USB 键盘”只打开厂商配置接口并读取配置，不会写入。需要 USB 数据线、有线模式，以及 Chrome／Edge 的设备选择授权。当前连接功能允许有界只读查询；普通键盘与鼠标报告仍受浏览器保护。[Chrome WebHID 文档](https://developer.chrome.com/docs/capabilities/hid)

“配置文件 → 查看本地备份”可以下载此前在同一浏览器、同一网址保存的备份。不要清理网站数据；切换浏览器或网址不会自动带上旧备份。备份导入仅供编辑区预览，不能恢复设备。

“配置文件 → 导出排查资料”下载浏览器版本、当前读取的配置、编辑区、已有本地备份及新版只读请求、回复、耗时和错误日志。日志单独存于浏览器本地数据库，刷新后仍可导出；存储失败会在导出时说明，并附上当前会话的内存记录。文件包含按键与宏内容，保存在你的电脑，不会自动上传。新记录不能重建 0.1.0 故障时实际发送的包。

不必重新连接或读取键盘，也可以导出已有备份；空日志会如实保留为空。之前 0.1.0 的日志无法补生成。

## 写入停用措施

页面写入按钮、配置写入入口及底层 USB 发送接口均阻止设备修改。底层只允许设备信息、灯光参数、当前键位、颜色、宏区和 LED 索引的查询；写命令、未知命令、越界或带数据的伪查询在发送前拒绝。没有启用写入的参数、地址开关或本地设置。

新版不会自动回滚或重发写命令。0.1.0 的旧包和历史源码不受新版保护，不能继续用来写入键盘。

## 验证与调查状态

0.1.1 的离线测试检查写入入口零设备操作、写命令及未知命令零发送、查询边界、读取、超时、断线、配置解析和预览。此前 0.1.0 的模拟读写测试通过，**但没有证明真实硬件写入可靠**。

查到网页版与原生程序的逐包等待节奏不同，原生灯效实物测试也未覆盖一次大批量逐键配色。根因尚未确认，不能只加延迟就宣布修复。[本次异常排查记录](../docs/网页版灯效异常排查.md)

## 开发验证

仅开发自测需要 Node，不影响 PHP 部署：

```sh
node --test tests/core.test.mjs
php -l index.php
```

测试使用模拟设备，不连接或修改实体键盘。部署只需要 `index.php` 与 `assets`；`package.json` 仅指定测试模块类型，没有依赖与构建步骤。

拿到导出的排查文件后，可离线校验已有回复，并比较相邻备份的灯光参数、颜色位置、键位位置及宏区变化：

```sh
node tests/replay-diagnostics.mjs CherryMac-diagnostics.json
```

该脚本没有设备访问或发送操作。它只能分析实际记录，不会重现未记录的物理故障。
