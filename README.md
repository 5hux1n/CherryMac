# CherryMac

为 CHERRY MX 3.0S Pokémon Wireless 制作的原生 macOS 键盘配置软件。0.5 增加宏区备份、解码及实验性的宏与键位联合写入；仍处于开发验证阶段。

![USB 键盘配置界面](docs/USB键盘配置预览.png)

## 当前功能

- 109 个可点选键位。普通单键为正方形，右上角排列计算器、上一曲、播放/暂停、下一曲。
- USB 读取当前键位表、灯效参数、126 个逐键 RGB 颜色及 3071 字节宏区，自动保存备份。
- 编辑快捷键组合、截图、媒体键等，手动写入键位，并读取当前自定义表校验。
- 调整亮度、速度、自定义逐键颜色；保留未修改的固件参数。其他灯效模式尚未完成对应关系验证。
- 宏使用按键名称编辑，支持普通键、修饰键、延迟、保存与删除。可分配到选中按键，实验性联合写入宏与键位，执行一次；实体触发仍待验证。
- CherryMac 配置 JSON 导入、导出。导入载入编辑区，点击写入才改变设备。
- 可安装由 macOS 服务执行的“打开计算器”快捷操作，使用 ⌃⌥⌘C；实体计算器键的完整启动流程仍待复测。
- 保留可选 Mac 端适配，例如 F5 仅在浏览器中转换为 ⌘R。启动时默认暂停适配。

## 验证范围

实物设备为 USB `046A:01CE`。已实际读取配置，写入并恢复亮度和逐键颜色；写入计算器键映射后，原始 HID 报告确认输出 ⌃⌥⌘C。另已实际写入一个未绑定实体按键的 30 字节短宏，完整读回校验后恢复了原宏区；键位与灯效保持原样。设备已经恢复原配置。

实体键测试曾在松键前恢复映射，造成修饰键残留。后续代码加入持续松键检查，每个写入和恢复分块都检查按键状态；配置已变化、备份失败或无法确认松键时停止写入。恢复失败会保留备份并明确报告。新流程的模拟固件测试已通过，实体端完整复测尚未进行。

宏联合写入采用完整备份、先解除原宏绑定、等待有限宏结束、事件块先写及头部最后写、完整读回校验和失败恢复。重复或切换模式、鼠标宏及未知数据格式会被拒绝覆盖。模拟固件测试已覆盖这些恢复路径；实际硬件目前只验证了未绑定短宏的存储读写。

未验证：宏的实体执行、宏与键位联合写入的完整硬件流程、断电保存、切换蓝牙后的配置保留、蓝牙和接收器写入。USB 设置成功不能证明永久保存。Windows 导出文件暂不能直接导入本应用。

Mac 端适配匹配蓝牙 `0687:00E9` 和上述 USB 设备；真实键盘的来源关联和浏览器适配仍需实体验证。模拟输入与实际 macOS 事件通道测试已通过。

## 构建和使用

macOS 13 或更新版本，安装 Xcode 命令行工具后运行：

```sh
bash Source/build.sh
```

脚本执行逻辑、模拟固件与编辑器自测，生成 `CherryMac.app` 和 `CherryMac-0.5.0.zip`。按当前 Mac 架构构建，使用临时本地签名，未通过 Apple 公证。自测不会写入硬件或安装系统快捷操作。

USB 配置：连接数据线、切换有线模式，为应用开启输入监控权限，读取配置后点选编辑。写入期间松开全部按键，不要使用键盘。Mac 端按键适配还需要辅助功能权限；从菜单栏打开其设置，主动启用。

```sh
./CherryMac.app/Contents/MacOS/CherryMac --self-test
# 只读设备查询；需要测试进程的输入监控权限
./CherryMac.app/Contents/MacOS/CherryMac --hardware-read backup.json
```

具体流程见 [使用说明](docs/使用说明.md)。
