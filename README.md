# CherryMac

[项目网站](https://cherrymac.goforit.si/)

为 **CHERRY MX 3.0S 宝可梦无线键盘**提供 Mac 客户端和 PHP 网页版。点选键盘图，编辑快捷键、灯光和宏，保存或迁移配置。

**当前为界面预览版：可以读取、编辑和导出，暂时不能写入实体键盘。** 旧版网页发生过灯效写入异常，根因仍在排查。完整移植、宏实体触发和断电保留尚未完成验证。

## 找到你要用的功能

客户端和网页版采用相同的五个菜单，切换页面保留编辑区配置。

| 菜单 | 可以做什么 |
| --- | --- |
| 按键功能 | 点选按键，设置框选截图、刷新、媒体键、自定义组合键或禁用 |
| 灯效 | 在“内置灯效”调整模式、亮度、速度；在“逐键配色”选择单键或区域，设置颜色、渐变和熄灭 |
| 宏 | 添加按下、松开与延迟，保存一次执行的键盘宏，并分配到按键 |
| 配置与备份 | 导入／导出 JSON、查看已有备份、撤销编辑区修改 |
| 设备与诊断 | 查看设备状态与限制；网页导出排查资料；客户端打开 Mac 端适配设置 |

普通单键保持正方形。右上角计算器、上一曲、播放／暂停、下一曲位于 Num、/、×、− 上方。配置与诊断页面不再重复展示键盘图。

## 使用 Mac 客户端

支持 macOS 13 及更新版本，下载包适用于 Apple Silicon（M1 及更新芯片）；Intel 暂未验证。

1. 下载 ZIP，解压并将 `CherryMac.app` 放入“应用程序”。
2. 打开后可直接体验预览编辑。要读取真实配置，用 USB 数据线连接键盘并切换到有线模式，再点击“读取键盘”。读取后自动保存备份。
3. 修改按键、灯效或宏，点击页面中的保存按钮，再到“配置与备份”导出文件。编辑不改变实体键盘。

应用尚未经过 Apple 公证。遇到系统阻止打开时，先确认来源，再参考 [Apple 打开 App 的说明](https://support.apple.com/zh-cn/102445)。

Mac 端按键适配为独立功能，默认暂停。可从“设备与诊断”打开设置，主动启用浏览器 F5 → ⌘R 等映射；启用时需要输入监控及辅助功能权限，并让应用持续运行。蓝牙可用于此适配功能，无线配置写入仍未确认。

计算器快捷操作由 macOS 服务启动计算器，需要先安装。2026-10-02 的受限 USB 测试已完成实体键改写、系统计算器启动及原配置恢复；普通预览版仍不能写入。[实机验证结果](docs/计算器键实机验证.md)

## 使用网页版：PHP，无需构建

解压源码包，双击 `start.command`，用 Chrome 或 Edge 打开 <http://localhost:8768/>。也可在 Web 目录运行：

```sh
php -S 127.0.0.1:8768 -t .
```

网站部署只需上传 `index.php` 与整个 `assets` 到 HTTPS 的 PHP 网站。不需要 Composer、npm、数据库或打包构建。配置文件在浏览器本地处理，不上传服务器。

![网页版逐键配色](docs/网页版预览.png)

网页版提供 RGB、HEX、强度与区域配色，精细选项按需展开。逐键颜色为静态配色；目前不能为每个键独立设置动画或速度。

## 配置与故障排查

支持 CherryMac 配置和本型号 Windows 官方 JSON。Windows 导入前先读取键盘，以保留当前隐藏位置和未知参数；不支持的绑定会拒绝整个导入。导入仅改变编辑区，不能恢复实体键盘。

客户端自动备份位于 `~/Library/Application Support/CherryMac/HardwareBackups`。网页备份与查询日志保存在当前浏览器、当前网址的本地数据库；请下载保留，清理网站数据会删除它们。“设备与诊断 → 导出排查资料”可下载已有备份及新版查询记录。

请关闭旧版网页，不再使用 0.1.0 重复写入。已恢复正常的键盘请保持当前配置。当前客户端和网页在 USB 底层均拒绝写命令，没有开启写入的设置。

## 开发与验证

客户端需 Xcode 命令行工具，在仓库根目录运行 `bash Source/build.sh`，会先离线自测，再生成 `.app` 和 ZIP。网页核心自测运行 `node --test Web/tests/core.test.mjs`；仅开发测试需要 Node。

这些模拟测试不连接实体键盘，不能证明真实灯效故障已经修复。界面检查覆盖五个菜单、灯效子页、草稿保留、深色和窄屏；[本版审查与验证](docs/界面改版验证.md)列出证据与限制。

本项目与 CHERRY 官方没有关联。仓库不包含 Windows 安装程序、官方图形资源或用户导出的配置。
